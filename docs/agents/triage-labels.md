# Triage 라벨

스킬은 기본 triage 역할 다섯 가지를 기준으로 동작한다. 이 파일은 역할마다 이 저장소의 이슈 트래커에서 실제로 쓰는 라벨 문자열을 짝지어 둔다.

| mattpocock/skills 라벨 | 이 저장소의 라벨  | 의미                                                  |
| ---------------------- | ----------------- | ----------------------------------------------------- |
| `needs-triage`         | `needs-triage`    | 메인테이너의 검토가 필요한 이슈                       |
| `needs-info`           | `needs-info`      | 작성자의 추가 정보를 기다리는 이슈                    |
| `ready-for-agent`      | `ready-for-agent` | 명세가 충분해 AFK 에이전트가 바로 작업할 수 있는 이슈 |
| `ready-for-human`      | `ready-for-human` | 사람이 직접 구현해야 하는 이슈                        |
| `wontfix`              | `wontfix`         | 진행하지 않기로 한 이슈                               |

스킬이 역할을 언급하면(예: "AFK 작업 가능 triage 라벨을 붙인다") 이 표에서 그 역할의 라벨 문자열을 쓴다.

실제로 쓰는 라벨 이름이 달라지면 가운데 열(이 저장소의 라벨)을 수정하면 된다.
