# Triage 라벨

Skill들은 다섯 가지 기본 triage 역할(role)을 기준으로 동작합니다. 이 파일은 각 역할을 이 저장소의 이슈 트래커에서 실제로 쓰는 라벨 문자열에 대응시킵니다.

| mattpocock/skills 라벨 | 이 저장소의 라벨  | 의미                                     |
| ---------------------- | ----------------- | ---------------------------------------- |
| `needs-triage`         | `needs-triage`    | 메인테이너의 검토가 필요한 이슈          |
| `needs-info`           | `needs-info`      | 작성자의 추가 정보를 기다리는 중         |
| `ready-for-agent`      | `ready-for-agent` | 명세가 충분해 AFK agent가 바로 작업 가능 |
| `ready-for-human`      | `ready-for-human` | 사람이 직접 구현해야 함                  |
| `wontfix`              | `wontfix`         | 진행하지 않기로 함                       |

Skill이 역할을 언급하면(예: "AFK 작업 가능 triage 라벨을 붙인다") 이 표에서 해당하는 라벨 문자열을 사용합니다.

실제로 쓰는 라벨 이름이 달라지면 가운데 열(이 저장소의 라벨)을 수정하면 됩니다.
