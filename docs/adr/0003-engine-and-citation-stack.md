# 엔진은 Quartz v5, 인용은 citations 플러그인과 엔트리별 bib 파일

Quartz v5 저장소를 복제해 기준선 SHA를 기록하고, 필요하면 엔진 파일도 고친다. 위키링크, 태그 목록, alias, 번호 인용을 모두 기본 기능과 공식 플러그인으로 얻을 수 있어서다. 기준선 SHA는 `docs/engine.md`에 적는다. 고친 파일 목록은 기준선과의 `git diff`로 계산하고, 고친 이유는 그 파일 안의 주석으로 남긴다. 손으로 쓴 목록은 사본이 되어 실제와 어긋나기 때문이다.

- 인용은 `[@키]` 표기를 citations 플러그인이 번호로 바꾼다. 스타일은 IEEE CSL 파일을 저장소에 두고 쓴다.
- locale은 `en-US`로 둔다. 다른 locale은 빌드할 때마다 CSL locale 파일을 원격에서 받아 오기 때문이다. 대가로 참고문헌의 고정 문구가 영어로 나온다.
- 참고문헌은 엔트리 하나를 파일 하나(`bib/<키>.bib`)로 두고, 빌드 전에 합친다. 여러 인제스트 PR이 동시에 참고문헌을 고쳐도 충돌하지 않게 하려는 것이다.
- 슬러그는 영문 소문자 kebab-case로 둔다. v5는 슬러그를 소문자로 바꾸는데, 한글 파일명에서 어떻게 동작하는지는 확인되지 않았다.

## 고려한 대안

- Starlight: 프론트매터 스키마 검증이 내장돼 있고 npm으로 업그레이드할 수 있다. 하지만 위키링크와 계층 태그를 검증되지 않은 플러그인으로 메워야 한다.
- 루트 `bibliography.bib` 하나: 병렬 PR끼리 충돌한다.
