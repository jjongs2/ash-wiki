# LLM으로 글을 쓰는 위키는 검증하지 못한 주장을 어떻게 다루는가

티켓: #718

## 답

견준 곳은 검증하지 못한 주장을 네 갈래로 다룬다. 내보내지 않거나, 출처대로 고쳐 쓰거나, 표시하고 남기거나, 게시 밖에 두고 검토를 기다린다.

- **내보내지 않는다**: WikiChat은 근거가 뒷받침한 주장만 남기고, 남는 것이 없으면 모른다고 답한다(C1, C2). 위키백과도 인라인 인용이 필요한데 없는 내용은 지울 수 있고, 사실이 아니라고 확신하면 태그 대신 지우라고 한다(C6, C11).
- **고쳐 쓴다**: RARR은 출력을 출처로 다시 조사해, 뒷받침되지 않는 부분을 고치고 나머지는 되도록 그대로 둔다(C3).
- **표시하고 남긴다**: 위키백과는 지우기 전의 중간 단계로 citation needed 태그를 권하고(C7), 출처가 내용을 뒷받침하지 않으면 failed verification 태그를 달거나 지운다(C8). LLM이 쓴 것으로 보이는 기사에는 AI-generated 태그를 달아 검토를 기다린다(C13). 위키백과 스스로 태그가 몇 달, 몇 년 남아 밀린 일이 되는 것을 문제로 본다(C9). 출처 없는 문장 태그가 달린 기사는 약 58만 9천 개다(C10).
- **게시 밖에 둔다**: 위키백과는 LLM 번역 초벌을 사용자 공간이나 초안 공간에 두고, 두 언어에 능숙한 사람이 검토하기 전에는 기사에 넣지 않는다(C12).

나중에 다시 조사하는 길을 둔 곳은 적다. 위키백과 AI Cleanup은 LLM 글을 지울 때 인용한 출처가 진짜면 토론 페이지에 남겨, 나중에 사람이 쓸 글에 쓰게 한다(C14). 미리 지운 LLM 글을 되살리려면 내용과 출처를 다시 검토해야 한다(C15). Karpathy의 LLM 위키는 lint에서 웹 검색으로 메울 빈 곳을 찾는다(C16). STORM은 처리 단계 없이 문장의 약 15%가 뒷받침되지 않은 채 남았지만, 글을 게시하지 않았다(C4, C5). Grokipedia가 검증하지 못한 주장을 어떻게 다루는지는 찾지 못했다(C17).

이 저장소는 내보내지 않고, 한 번 다시 조사한다. 미검증 주장은 게시하지 않고 `verify:` 이슈에 남긴다(C18). 미검증과 제외는 다시 시도할 여지로 가른다(C19). 미검증에는 순위대로 사유 하나를 적고, 재조사는 사유마다 정한 방법으로 다시 찾는다(C20). 인제스트는 사유와 시도한 출처를 이슈에 남긴다(C21). 출처가 일부만 뒷받침하면 주장을 쪼개 그 부분만 게시하고, 출처가 다르게 말하면 출처대로 고쳐 쓴다(C22, C23). RARR의 고쳐 쓰기와 같은 방향이다(C3). 이미 게시한 주장과 어긋나는 출처를 가리지 못하면 페이지를 그대로 두고 `(게시됨)`으로 남긴다(C24). 검증 완료만으로 머리말을 채우지 못하는 페이지는 만들지 않고, 그 검증 완료 주장은 `보류`로 남아 주제 계획과 보강이 이어받는다(C25, C26). 재조사는 한 번이고, 닫힌 이슈의 미검증 항목은 다시 열지 않는다(C27). 독자 검토에서 새 출처가 있어야 메울 빈 곳은 보강이 다시 찾는다(C28).

닫힌 `verify:` 이슈 17개의 항목 1,048개 가운데 604개(58%)가 체크되었고 444개가 체크되지 않은 채 닫혔다(C29). 남은 항목의 절반 넘게(247개)는 `공개 범위 밖`이고, `출처 없음` 141개, `1층 없음` 45개가 뒤를 잇는다. `접근 실패`는 119개 가운데 9개만 남았다(C30). 남은 항목 대부분은 유료 원문에만 있어, 시간이 지나도 공개 출처가 생기지 않는 한 같은 방법으로는 풀리지 않을 것이다(추론).

**선택지(결정은 뒤 티켓).**

- **현행 유지**: 미검증은 게시하지 않고 한 번 재조사한다(C18, C27). 표시하고 게시하는 곳의 비용(밀린 태그)을 지지 않는다(C9, C10). 남은 444개는 보강이 주제를 새로 대조할 때까지 쓰이지 않는다(C28, C29).
- **닫힌 이슈의 미검증 항목도 이어받는다**: 지금은 `보류`만 슬러그로 찾아 이어받는다(C26). 미검증 항목과 시도한 출처까지 출처 후보로 넘기면, 위키백과가 지운 글의 출처를 토론 페이지에 남기는 것과 같은 꼴이 된다(C14). 바꿀 규칙은 위키 검증의 게시 기준과 재조사 절이다. 남은 항목 대부분이 `공개 범위 밖`이라(C30) 얻는 것이 적을 수 있다(추론).
- **사유에 따라 다시 시도할 때를 둔다**: `접근 실패`와 `출처 없음`은 시간이 지나면 열리거나 새 출처가 나올 수 있다(추론). 닫힌 이슈를 다시 열지 않는 규칙(C27)을 사유별로 푸는 것이다. 다시 시도할 때와 맡을 흐름을 정해야 한다.
- **표시하고 게시한다**: 위키백과의 citation needed 꼴이다(C7). "게시되는 것은 검증 완료뿐"이라는 판정 절의 규칙(C18)을 뒤집는다. 위키백과는 이 꼴이 밀린 일을 쌓는다고 본다(C9). 이 기록은 이 안을 뒷받침하는 근거를 찾지 못했다.
