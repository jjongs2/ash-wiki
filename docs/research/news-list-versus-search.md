# 정해진 목록(피드, 뉴스룸)과 검색(질의, 자유 검색)은 무엇을 나눠 맡는가

티켓: #769

## 답

**목록 훑기와 검색은 서로 다른 것을 놓친다.** 체계적 문헌고찰이 이 갈래를 직접 쟀다. 정해진 학술지를 처음부터 끝까지 손으로 훑으면 찾은 보고의 92\~100%를 잡았고, MEDLINE 검색은 55%였다(C1). 검색은 질의를 잘 짤수록 나아져, 단순한 질의는 42%, 민감도를 높인 질의는 80%를 찾았다(C2). 영어 밖 학술지에서는 39%로 떨어졌다(C3). 손으로 훑기가 따로 잡는 것은 초록, 편지, 영어 밖 언어의 보고, 색인되지 않은 학술지다(C4). 반대로 색인된 영어 학술지의 정식 보고는 잘 짠 검색으로 대부분 잡힌다(C5). Cochrane은 데이터베이스 하나로 끝내지 말고 여럿을 보고, 손으로 훑기와 실린 연구의 참고문헌 확인을 더하라고 한다(C6, C7, C8). 실제로 고찰이 실은 문헌 가운데 데이터베이스 검색 밖의 방법으로만 찾은 것이 있었다(C9).

**검색과 링크 따라가기는 목록 밖으로 넓힌다.** Media Cloud는 일을 둘로 나눈다. 정해진 출처 약 6만 곳의 피드를 늘 받는 수집기가 하나이고, 주제마다 질의로 씨앗을 모아 링크를 따라 목록 밖까지 찾는 엔진이 하나다(C10, C11). 저자들은 목록 밖으로 나가지 못하는 것을 상용 뉴스 데이터베이스와의 차이로 든다(C12). 목록은 아는 출처를 빠짐없이 받고, 검색은 모르는 출처를 찾는다.

| 맡는 것              | 정해진 목록(손으로 훑기, 피드)      | 검색(질의, 링크 따라가기)               | 근거         |
| -------------------- | ----------------------------------- | --------------------------------------- | ------------ |
| 아는 출처의 빠짐없음 | 강하다. 낱말과 색인에 기대지 않는다 | 질의 낱말과 색인에 달렸다               | C1, C2, C4   |
| 언어와 비정형 글     | 강하다                              | 영어 밖, 초록·편지에서 약하다           | C3, C4       |
| 목록 밖의 출처       | 못 한다                             | 맡는다                                  | C9, C10, C12 |
| 자원이 모자랄 때     | 덜 쓴다                             | 색인된 정식 보고는 대부분 잡는 대안이다 | C5           |

**LLM 에이전트 사례.** 공개 사례는 한쪽에 기운다. auto-news는 RSS, Reddit, 트윗 같은 피드를 모으고(C13), AINews는 정해진 subreddit, 트위터 계정, Discord를 호마다 훑는다(C15). gpt-newspaper는 주제를 몇 개의 뉴스 검색으로 바꿔 돌릴 뿐 정해진 목록이 없다(C14). 둘을 어떻게 나누고 각자의 몫을 어떻게 재는지 밝힌 사례는 찾지 못했다(C27).

**이 저장소의 현행.** 목록과 검색을 함께 쓰는 것은 문헌고찰의 권고와 맞는다(C7, C8). 매체 목록, 검색 질의, 구역마다 한두 번의 자유 검색 순으로 살핀다(C16). `제목으로 고름`인 매체는 키워드로 먼저 거르지 않고 그 주의 제목을 모두 읽어, 손으로 훑기와 같은 꼴이다(C18). 제3자 기사에서 보도자료 링크를 따라 1차 발표를 찾는 것은 참고문헌 확인과 같다(C8, C22).

다른 것은 셋이다.

- **목록의 3분의 1이 검색이다.** 매체 95곳 가운데 34곳은 찾는 법이 검색 질의이고, 루틴 환경에서 열리지 않는 곳도 검색 질의로 둔다(C17). 뉴스룸이 막힌 실행은 Google News `site:` 질의로 대신 훑었다(C23). 이런 줄은 손으로 훑기가 아니라 검색의 성질(색인과 질의 낱말에 기댐)을 진다.
- **검색 질의는 실마리다.** Google News 질의는 원문 주소를 주지 않고, 기간 밖의 항목이 섞이며, 가끔 0건을 돌려준다(C19, C20). 질의 낱말이 표기 하나를 놓쳐 고친 일도 있다(C24). 단순한 질의가 덜 찾는다는 C2와 같은 방향이다.
- **나눈 몫을 재지 않는다.** 검색에서만 찾은 원문은 작업 파일에 목록 밖으로 표시하지만(C21), 공개되는 판정표에는 찾은 길이 없다(C25). 43\~46주차 호 120건 가운데 86건은 `매체`가 목록 안이지만(C26), 1차 발표로 바꿔 실은 항목도 있어 이것이 목록이 찾은 몫은 아니다. 목록과 검색이 각자 무엇을 맡았는지 공개 기록으로는 셀 수 없다.

**선택지(결정은 뒤 티켓).**

- **현행 유지**: 목록, 질의, 자유 검색의 순서와 손으로 훑기를 그대로 둔다(C16, C18).
- **찾은 길을 남긴다**: 실린 항목마다 찾은 그룹과 매체를 판정표에 남겨, 검색에서만 찾은 몫과 목록에서만 찾은 몫을 센다(C21, C25). 놓침 측정(#769의 첫 질문)과 목록 기여도(둘째 질문)의 재료가 된다.
- **검색 질의인 목록 줄을 따로 본다**: 찾는 법이 검색 질의인 34곳은 손으로 훑기가 아니라 검색의 놓침을 진다고 보고, 뉴스룸이나 피드가 열리면 그쪽으로 옮긴다(C17, C23).
