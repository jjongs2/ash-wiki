# 결정 로그

꼴의 예시는 코드 블록이라 항목으로 읽지 않는다.

```markdown
- D99 <고른 것>
```

## 항목

<!-- 주석 안의 줄도 항목으로 읽지 않는다 -->

- D1 (D3이 대체) 채택: 규칙 하나를 둔다. 기각: 규칙 둘.
  까닭: 첫 까닭. 원래 까닭: 근거 불명.
  규칙: [규칙 하나](rules.md#규칙-하나). 근거: #1
- D2 (ADR 1이 대체) 규칙 셋을 둔다.
  버린 것: 규칙 넷.
  까닭: 둘째 까닭.
  규칙: 없음. 근거: [조사](rules.md)
- D3 보류: 규칙 다섯. 버린 것: 규칙 여섯. 까닭: 다시 볼 조건. 규칙: 없음. 근거: #3
  대체: D1
