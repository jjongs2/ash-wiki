ISO 11898-2:2026은 트랜시버를 정한다. ISO 11898-2는 우성을 구동하도록 정한다.[@iso-11898-2-obp-2026]

ISO 11898-1:2024는 오버로드 프레임을 정의한다.[@iso-11898-1-2024] Bosch CAN 2.0 규격은 오버로드 프레임을 두 필드로 정한다.[@bosch-can-2-0-1991]

Bosch CAN 2.0 규격은 오버로드 조건을 셋으로 정한다.[@bosch-can-2-0-1991]

ISO 11898-1:2024는 비트 스터핑을 정한다. ISO 11898-1은 스터핑 비트를 다섯 비트마다 넣도록 정한다.[@iso-11898-1-2024]

ISO 11898-1:2024는 스터핑 오류를 오류 프레임으로 알리도록 정한다.[@iso-11898-1-2024]
