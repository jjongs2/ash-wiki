## 범위

- `owner-page`: 오류 계수기.

주인 페이지:

| 개념         | 주인                      | 링크만 하는 곳                                                                                |
| ------------ | ------------------------- | --------------------------------------------------------------------------------------------- |
| 오류 계수기  | `owner-page`              | `linker-a`, `linker-b`, `missing-page`. 다른 구역의 `other-page`는 고치지 않는다(린트가 링크) |
| 계획 없는 것 | 다른 주제(아직 계획 없음) | `linker-a`. 이름만 두고 링크하지 않는다.                                                      |
| 아직 없는 것 | `planned-page`            | `linker-b`                                                                                    |
