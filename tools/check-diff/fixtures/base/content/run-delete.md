TI 앱노트에 따르면 PHY는 MAC과 매체 사이에 있다.[@ti-phy-note-2020]

IEEE 802.3-2022는 PHY가 전이중으로 주고받도록 정한다.[@ieee-802-3-2022]

## 동작

이 표준은 PHY가 마스터와 슬레이브로 동작하도록 정한다.[@ieee-802-3-2022]

![[diagrams/new-figure.svg]]

슬레이브는 받은 신호에서 클럭을 복구한다.[@ieee-802-3-2022]
