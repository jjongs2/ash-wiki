P1722.1
Standard for Device Discovery, Connection Management, and Control Protocol for Time-Sensitive Networking Systems

This standard specifies stream setup, control, and teardown protocols, device discovery, connection management, and device control procedures that facilitate interoperability between systems using IEEE 802 time-sensitive networking standards.
