**ISO 26262**는 도로 차량에 실리는 E/E(Electrical/Electronic) 시스템의 [[functional-safety|기능 안전]]을 다루는 국제 표준 시리즈다. 시리즈 제목은 "Road vehicles — Functional safety"이고, ISO/TC 22/SC 32가 맡는다. [[iec-61508|IEC 61508]]을 도로 차량 E/E 시스템의 분야 요구에 맞게 고친 표준이다.[@iso-26262-1-obp-2018]

## 범위

ISO 26262:2018은 양산 도로 차량에 설치되는, E/E 시스템을 하나 이상 포함한 안전 관련 시스템에 적용한다. 모페드는 제외한다. 장애인 운전자를 위한 시스템처럼 특수 차량에만 있는 E/E 시스템도 다루지 않는다.[@iso-26262-1-obp-2018]

ISO 26262:2018은 12개 부로 이뤄진다.[@iso-26262-10-obp-2018]

| 부      | 다루는 것                                                              |
| ------- | ---------------------------------------------------------------------- |
| Part 1  | 용어                                                                   |
| Part 2  | 기능 안전 관리                                                         |
| Part 3  | Concept phase                                                          |
| Part 4  | 시스템 수준 제품 개발                                                  |
| Part 5  | 하드웨어 수준 제품 개발                                                |
| Part 6  | 소프트웨어 수준 제품 개발                                              |
| Part 7  | 생산, 운용, 서비스, 폐기                                               |
| Part 8  | 지원 프로세스                                                          |
| Part 9  | [[automotive-safety-integrity-level\|ASIL]] 중심 분석과 안전 중심 분석 |
| Part 10 | ISO 26262 지침                                                         |
| Part 11 | 반도체에 적용하는 지침                                                 |
| Part 12 | 모터사이클에 맞춘 적용                                                 |

ISO 26262-2:2018은 부록에서 safety culture와 confirmation measures를 다룬다.[@iso-26262-2-obp-2018] ISO 26262-8:2018이 정하는 지원 프로세스에는 소프트웨어 도구 사용의 신뢰도, 소프트웨어 컴포넌트의 qualification, proven in use 논증이 든다.[@iso-26262-8-2018] 단계의 흐름은 [[safety-lifecycle|안전 생명주기]]에서, [[iso-21448|ISO 21448]]과의 비교는 [[sotif#ISO 26262와의 차이|SOTIF]]에서 다룬다.

## 개정 이력

- 2011년: 1판. Part 1–10으로 이뤄졌고[@iso-26262-1-obp-2011], Part 1이 2011년 11월에[@iso-26262-1-2011], Part 10이 2012년 8월에 나왔다.[@iso-26262-10-2012] ISO 26262-1:2011은 적용 대상을 최대 총중량 $m$이 $m \le 3500\,\mathrm{kg}$인 양산 승용차로 정했다.[@iso-26262-1-2011]
- 2018년: 2판이자 현행판. 12월에 나왔다.[@iso-26262-1-2018] 적용 대상을 모페드를 뺀 양산 도로 차량으로 넓히고, 트럭, 버스, 트레일러, 세미트레일러와 모터사이클의 요구사항을 더했다. 반도체 지침도 이 판에 더해졌다.[@iso-26262-1-obp-2018]
- 3판이 ISO/DIS(Draft International Standard) 26262-1로 개발 중이다.[@iso-dis-26262-1-2026]

## IEC 61508과의 관계

IEC 61508은 응용 분야와 상관없이 E/E/PE(Electrical/Electronic/Programmable Electronic) 안전 관련 시스템의 모든 안전 생명주기 활동에 일반 접근을 정하고, 분야별 국제 표준을 그 위에 만들도록 한다.[@iec-61508-4-preview-2010] ISO 26262는 IEC 61508을 도로 차량 분야의 요구에 맞게 고친 것이고, 자동차에 맞춘 리스크 기반 방법으로 ASIL을 정한다.[@iso-26262-1-obp-2018] 두 등급의 비교는 [[automotive-safety-integrity-level#SIL과의 차이|ASIL]]에서 다룬다.
