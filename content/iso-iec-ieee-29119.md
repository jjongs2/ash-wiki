**ISO/IEC/IEEE 29119**는 소프트웨어 테스트의 개념, 프로세스, 문서, 기법을 다루는 국제 표준 시리즈다. ISO/IEC JTC 1/SC 7이 IEEE Computer Society와 맺은 협약에 따라 준비하고, ISO, IEC, IEEE가 함께 펴낸다.[@iso-iec-ieee-29119-1-obp-2022] 시리즈 제목은 "Software and systems engineering — Software testing"이다.[@iso-iec-ieee-29119-1-2022]

## 범위

ISO/IEC/IEEE 29119 시리즈는 어느 조직에서든, 어느 생명주기에서든, 어떤 형태의 소프트웨어 테스트에도 쓸 수 있는 테스트 표준의 묶음을 정하고, 조직이 테스트를 관리하고 수행하는 데 쓰게 한다.[@iso-iec-ieee-29119-1-obp-2022] 부마다 다루는 것은 다음과 같다.

| 부           | 제목                   | 다루는 것                                                                                                                                                            |
| ------------ | ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 29119-1:2022 | General concepts       | 소프트웨어 테스트의 일반 개념과 용어. 다른 부가 기대는 개념을 소개해 다른 부를 쓰기 쉽게 한다[@iso-iec-ieee-29119-1-obp-2022]                                        |
| 29119-2:2021 | Test processes         | 조직 수준, 테스트 관리 수준, 동적 테스트 수준의 테스트 프로세스[@iso-iec-ieee-29119-2-obp-2021]                                                                      |
| 29119-3:2021 | Test documentation     | 테스트 프로세스가 만드는 문서(테스트 정책, 테스트 계획서, 테스트 완료 보고서, 테스트 케이스·절차 명세, 테스트 사건 보고서 등)의 서식[@iso-iec-ieee-29119-3-obp-2021] |
| 29119-4:2021 | Test techniques        | 테스트 설계 기법과 그 커버리지 측정[@iso-iec-ieee-29119-4-obp-2021]                                                                                                  |
| 29119-5:2024 | Keyword-driven testing | 키워드 기반 테스트[@iso-iec-ieee-29119-5-2024]                                                                                                                       |

이 밖에 ISO와 IEC가 펴낸 기술 보고서 ISO/IEC TR 29119-6:2021은 애자일 생명주기에서 29119를 쓰는 지침을,[@iso-iec-tr-29119-6-2021] ISO/IEC TR 29119-11:2020은 AI(artificial intelligence) 기반 시스템을 테스트하는 지침을 담는다.[@iso-iec-tr-29119-11-2020]

29119-2의 프로세스 모델은 [[test-process|테스트 프로세스]]에서, 테스트 케이스와 그 구성은 [[test-case|테스트 케이스]]에서 다룬다.

## IEEE 829, BS 7925와의 관계

IEEE 829는 소프트웨어와 시스템의 테스트 문서를 다루는 IEEE 표준으로, 1983년에 처음 나와 1998년과 2008년에 개정되었다. IEEE SA는 IEEE 829-2008이 29119-1:2013, 29119-2:2013, 29119-3:2013, 29119-4:2015로 대체되었다고 적는다.[@ieee-829-2008]

BSI(British Standards Institution)의 BS 7925-1:1998(소프트웨어 테스트 용어)은 2013년 9월 30일에 철회되었고, BSI 기록에서 그 이력이 BS ISO/IEC/IEEE 29119-1로 이어진다.[@bs-7925-1-1998] BS 7925-2:1998(소프트웨어 컴포넌트 테스트)은 2015년 12월 31일에 철회되었고, 이력이 BS ISO/IEC/IEEE 29119-4로 이어진다.[@bs-7925-2-1998] 29119-4는 처음에 BS 7925-2를 바탕으로 만들어졌다.[@iso-iec-ieee-29119-4-obp-2021]
