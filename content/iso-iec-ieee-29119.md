**ISO/IEC/IEEE 29119**는 [[software-testing|소프트웨어 테스트]]의 개념, 프로세스, 문서, 기법을 다루는 국제 표준 시리즈다. ISO/IEC JTC 1/SC 7이 IEEE Computer Society와 맺은 협약에 따라 준비하고, ISO, IEC, IEEE가 함께 펴낸다.[@iso-iec-ieee-29119-1-obp-2022] 시리즈 제목은 "Software and systems engineering — Software testing"이다.[@iso-iec-ieee-29119-1-2022]

## 범위

ISO/IEC/IEEE 29119 시리즈는 어느 조직에서든, 어느 생명주기에서든, 어떤 형태의 소프트웨어 테스트에도 쓸 수 있는 테스트 표준의 묶음을 정하고, 조직이 테스트를 관리하고 수행하는 데 쓰게 한다.[@iso-iec-ieee-29119-1-obp-2022] 부마다 다루는 것은 다음과 같다.

| 부           | 제목                   | 다루는 것                                                                                                                                                                                                                      |
| ------------ | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 29119-1:2022 | General concepts       | 소프트웨어 테스트의 일반 개념과 용어. 다른 부가 기대는 개념을 소개해 다른 부를 쓰기 쉽게 한다.[@iso-iec-ieee-29119-1-obp-2022]                                                                                                 |
| 29119-2:2021 | Test processes         | 조직 수준, 테스트 관리 수준, 동적 테스트 수준의 [[test-process\|테스트 프로세스]][@iso-iec-ieee-29119-2-obp-2021]                                                                                                              |
| 29119-3:2021 | Test documentation     | 테스트 프로세스가 만드는 문서(테스트 정책, [[test-process#테스트 계획서\|테스트 계획서]], 테스트 완료 보고서, [[test-case\|테스트 케이스]]·절차 명세, 테스트 사건 보고서 등)의 서식[@iso-iec-ieee-29119-3-obp-2021]            |
| 29119-4:2021 | Test techniques        | 테스트 설계 기법과 그 커버리지 측정[@iso-iec-ieee-29119-4-obp-2021]                                                                                                                                                            |
| 29119-5:2024 | Keyword-driven testing | [[keyword-driven-testing\|키워드 기반 테스트]]의 소개와 참조 접근, 키워드 기반 테스트 프레임워크와 이를 지원하는 도구의 요구사항, 도구 사이의 공통 데이터 교환 형식, 일반적인 하위 키워드의 예[@iso-iec-ieee-29119-5-obp-2024] |

이 밖에 ISO와 IEC가 펴낸 기술 보고서 ISO/IEC TR 29119-6:2021은 [[agile-software-development|애자일]] 생명주기에서 29119를 쓰는 지침을[@iso-iec-tr-29119-6-2021], ISO/IEC TR 29119-11:2020은 AI 기반 시스템을 테스트하는 지침을[@iso-iec-tr-29119-11-2020], ISO/IEC TR 29119-13:2022는 생체 인식 시스템과 생체 인식 하위 시스템이 든 시스템을 29119 시리즈에 맞춰 리스크 기반으로 테스트하는 데 쓸 정보와, 생체 인식 테스트 표준과 29119 시리즈 사이의 대응을 담는다.[@iso-iec-tr-29119-13-obp-2022]

29119-5:2024는 29119-2가 정한 테스트 설계·구현 프로세스를 키워드 기반 테스트에 맞게 구현하는 방식, 특히 TD3과 TD4의 구현을 다룬다.[@iso-iec-ieee-29119-5-obp-2024] 29119-2:2021의 Annex A(informative)는 테스트 설계·구현 프로세스를 적용한 예를 TD1부터 TD4까지 나눠 제시하며, TD3에서 테스트 케이스를, TD4에서 테스트 절차를 다룬다.[@iso-iec-ieee-29119-2-obp-2021]

## 개정 이력

- 2013년 9월: 29119-1(Concepts and definitions), 29119-2, 29119-3 첫판.[@iso-iec-ieee-29119-1-2013][@iso-iec-ieee-29119-2-2013][@iso-iec-ieee-29119-3-2013]
- 2015년 12월: 29119-4 첫판.[@iso-iec-ieee-29119-4-2015]
- 2016년 11월: 29119-5 첫판.[@iso-iec-ieee-29119-5-2016]
- 2021년: 29119-2, 29119-3, 29119-4 둘째 판. 각각 첫판을 대체했다.[@iso-iec-ieee-29119-2-obp-2021][@iso-iec-ieee-29119-3-obp-2021][@iso-iec-ieee-29119-4-obp-2021] 29119-4:2021은 테스트 기법을 29119-2의 새 테스트 설계·구현 프로세스로 정의하면서, 테스트 케이스를 끌어내는 바탕을 테스트 조건에서 테스트 모델로 바꿨다.[@iso-iec-ieee-29119-4-obp-2021]
- 2022년: 29119-1 둘째 판. 2013년 판을 대체했고, 제목이 Concepts and definitions에서 General concepts로 바뀌었다. 29119-1:2022는 이 부가 다루지 않는 테스트 용어의 정의를 뺐고, 복잡한 테스트 하위 프로세스(test sub-process) 개념을 없앴으며, 테스트 케이스를 테스트 조건이 아니라 테스트 모델에서 끌어내는 단순한 테스트 설계 프로세스를 담았다.[@iso-iec-ieee-29119-1-obp-2022]
- 2024년 12월: 29119-5 둘째 판. 2016년 판을 대체했다.[@iso-iec-ieee-29119-5-2024] 29119-5:2024는 테스트 설계·구현 프로세스와 테스트 절차 문서의 참조를 29119-2:2021과 29119-3:2021에 맞춰 고쳤고, 29119-1:2022에 바탕을 둔 용어 정의를 넣었다.[@iso-iec-ieee-29119-5-obp-2024]
- 현행판: 29119-1:2022, 29119-2:2021, 29119-3:2021, 29119-4:2021, 29119-5:2024. 2026년 10월 기준 어느 부도 개정이 진행되고 있지 않다.[@iso-iec-ieee-29119-1-2022][@iso-iec-ieee-29119-5-2024][@iso-iec-ieee-29119-2-2021][@iso-iec-ieee-29119-3-2021][@iso-iec-ieee-29119-4-2021]

## IEEE 829, BS 7925와의 관계

IEEE 829는 소프트웨어와 시스템의 테스트 문서를 다루는 IEEE 표준으로, 1983년에 처음 나와 1998년과 2008년에 개정되었다.[@ieee-829-1983][@ieee-829-1998] IEEE 829-2008은 29119-1:2013, 29119-2:2013, 29119-3:2013, 29119-4:2015로 대체되었다.[@ieee-829-2008]

BSI의 BS 7925-1:1998(소프트웨어 테스트 용어)은 2013년 9월 30일에 철회되었고, BSI 기록은 이 표준의 이력(History)에 BS ISO/IEC/IEEE 29119-1을 올린다.[@bs-7925-1-1998] BS 7925-2:1998(소프트웨어 컴포넌트 테스트)은 2015년 12월 31일에 철회되었고, 이력에는 BS ISO/IEC/IEEE 29119-4가 올라 있다.[@bs-7925-2-1998] 두 기록 모두 29119의 부가 이 표준들을 대체했다고 적지는 않는다.[@bs-7925-1-1998][@bs-7925-2-1998] 29119-4는 처음에 BS 7925-2를 바탕으로 만들어졌다.[@iso-iec-ieee-29119-4-obp-2021]
