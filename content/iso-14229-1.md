**ISO 14229-1**은 [[uds|UDS]]의 응용 계층을 정하는 국제 표준이다.[@iso-14229-1-obp-2026] 정식 제목은 "Road vehicles — Unified diagnostic services (UDS) — Part 1: Application layer"이다.[@iso-14229-1-2026]

## 범위

진단 장비가 클라이언트, [[electronic-control-unit|ECU]]가 서버가 되어, 클라이언트가 서버의 진단 기능을 제어하게 하는 진단 통신 서비스를 정한다. 이 요구사항은 특정 데이터 링크에 매이지 않는다. 이 서비스로 진단 장비는 비진단 메시지 송신을 멈추거나 다시 시작하고, 차량 식별 데이터와 실시간 센서 데이터를 읽고, 진단 정보를 읽고 지우고, 액추에이터를 제어하고, 루틴을 시작하거나 멈추는 등 차량 전자 시스템의 진단을 돕는 일을 한다.[@iso-14229-1-obp-2026]

이 표준은 차량 통신 데이터 링크에서 두 ECU 사이에 오가는 비진단 메시지 송신에는 적용하지 않는다. 또 ECU(서버) 안에 차량 탑재 진단 장비(클라이언트)를 구현해 진단 통신 서비스로 양방향 진단 데이터를 주고받는 것도 막지 않는다. 서비스마다 요청 메시지, 긍정 응답 메시지, 지원하는 [[uds#부정 응답 코드|NRC]]를 적는 규약을 두고, 진단·통신 관리 기능 단위에 SecurityAccess(`0x27`) 같은 서비스를 둔다. 구현 요구사항은 정하지 않는다.[@iso-14229-1-obp-2026]

## 개정 이력

- 2006년: 첫판.[@iso-14229-1-obp-2013]
- 2013년: 2판. 제목의 부 이름은 "Specification and requirements"였다.[@iso-14229-1-obp-2013]
- 2020년: 3판. 부 이름을 "Application layer"로 바꾸고, [[cybersecurity|사이버보안]]을 다루는 Authentication 서비스(`0x29`)와 "Security sub-layer definition" 절을 새로 넣었다.[@iso-14229-1-obp-2020]
- 2022년: 2020년판의 Amendment 1(ISO 14229-1:2020/Amd 1:2022)이 나왔다.[@iso-14229-1-2026]
- 2026년: 4판. 2020년판을 대체하고 ISO 14229-1:2020/Amd 1:2022를 합쳤다. 주된 변경은 ResponseOnEvent 서비스에 관한 정정이다.[@iso-14229-1-obp-2026]
