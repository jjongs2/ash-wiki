**페어와이즈 테스트**(pairwise testing)는 두 매개변수 값의 가능한 모든 쌍을 적어도 한 테스트 케이스가 덮게 하는 [[black-box-testing|블랙박스]] 기법이다.[@istqb-glossary-pairwise-testing-2026][@nist-sp-800-142-2010] NIST SP 800-142에 따르면 페어와이즈 테스트는 두 매개변수의 조합(2-way 조합)을 덮는 조합 테스트이고, 조합 테스트에서 흔히 쓰는 방식으로 자리 잡았다.[@nist-sp-800-142-2010]

## 조합 테스트

ISTQB(International Software Testing Qualifications Board) 용어집은 **조합 테스트**(combinatorial testing)를 여러 매개변수 값의 특정 조합을 테스트 조건으로 삼는 블랙박스 기법으로 정의한다.[@istqb-glossary-combinatorial-testing-2026]

NIST SP 800-142에 따르면 매개변수 t개의 값 조합을 모두 덮는 테스트를 t-way 조합 테스트라 하고, t를 강도(strength)라고도 부른다. 페어와이즈 테스트는 t가 2인 경우다.

이 문서에 따르면 소프트웨어 실패는 대부분 매개변수 하나의 값이나 두 매개변수의 상호작용으로 일어나고, 얽힌 매개변수가 많을수록 그런 실패는 드물어진다. NIST와 다른 연구자가 조사한 분야에서는 모든 실패가 많아야 매개변수 4개에서 6개의 상호작용으로 일어났고, 이 관찰이 조합 테스트의 근거다.[@nist-sp-800-142-2010]

## 케이스 수

NIST SP 800-142의 예에서 값이 둘인 매개변수 10개의 모든 조합은 $2^{10} = 1024$개지만, 그 3-way 조합은 모두 13개 케이스로 덮인다. 값이 각각 3, 2, 2, 2, 3가지인 매개변수 5개의 구성 72가지는 10개 케이스로 모든 쌍을 덮는다.

이 문서에 따르면 매개변수 $n$개가 각각 값 $v$개를 가질 때, t-way 조합을 모두 덮는 케이스 수는 $v^t \log n$에 비례한다. 그래서 케이스 수는 매개변수 수의 로그로만 늘어난다.[@nist-sp-800-142-2010]

## 직교 배열과 커버링 배열

NIST SP 800-142에 따르면 조합 테스트의 핵심 요소는 모든 t-way 조합을 담은 커버링 배열이다. 커버링 배열에서 행 하나는 테스트 하나, 열 하나는 매개변수 하나다.

- **직교 배열**(orthogonal array): 어느 t개 열을 골라도 값의 모든 t-튜플이 정확히 같은 횟수씩 나오는 배열이다.
- **커버링 배열**(covering array): 어느 t개 열을 골라도 값의 모든 t-튜플이 적어도 정해진 횟수만큼 나오는 배열이다. 소프트웨어 테스트에서는 그 횟수를 1로 둔다.

이 문서에 따르면 커버링 배열은 조합마다 같은 횟수씩 나와야 한다는 제약을 풀어서, 테스트가 겹칠 수는 있지만 직교 배열로는 다룰 수 없는 훨씬 큰 문제에도 계산할 수 있다.[@nist-sp-800-142-2010]

## 도구

NIST SP 800-142에 따르면 모든 t-way 조합을 덮는 테스트 집합을 효율적으로 만드는 일은 어려운 수학 문제여서, 테스트 데이터 생성 도구로 정한 강도까지의 조합을 덮는다. NIST의 ACTS(Automated Combinatorial Testing for Software)는 2-way부터 6-way까지의 조합을 덮는 커버링 배열 생성기다.[@nist-sp-800-142-2010]

Microsoft의 PICT(Pairwise Independent Combinatorial Testing)는 매개변수 모델 파일에서 테스트 케이스를 생성한다. 기본으로 모든 값 쌍을 덮고, 옵션으로 더 높은 차수의 조합도 덮는다.[@microsoft-pict-2026]
