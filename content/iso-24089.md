**ISO 24089**는 도로 차량의 소프트웨어 업데이트 엔지니어링에 대한 요구사항과 권고를 정하는 국제 표준이다.[@iso-24089-obp-2023] 정식 제목은 "Road vehicles — Software update engineering"이고, ISO/TC 22/SC 32가 맡는다.[@iso-24089-2023]

## 범위

ISO 24089:2023은 도로 차량의 소프트웨어 업데이트 엔지니어링에 대해 조직 수준과 프로젝트 수준의 요구사항과 권고를 정한다. 이 요구사항과 권고는 차량, 차량 시스템, ECU, 인프라에 적용되고, 초기 개발 뒤 소프트웨어 업데이트 패키지를 조립하고 배포하는 일에도 적용된다. 소프트웨어를 업데이트할 수 있는 도로 차량과, 차량 제조사와 공급자처럼 소프트웨어 업데이트 엔지니어링에 관여하는 조직이 대상이다. 소프트웨어 업데이트 엔지니어링을 뺀 차량 기능 소프트웨어의 개발은 범위 밖이고, 특정 기술이나 솔루션을 정하지 않는다.[@iso-24089-obp-2023]

ISO 24089:2023은 [[iso-26262|ISO 26262]]-6, ISO 26262-8, [[iso-sae-21434|ISO/SAE 21434]]를 인용 표준으로 둔다. 소프트웨어 업데이트 엔지니어링은 소프트웨어 업데이트 패키지를 계획하고 개발하고 배포하는 프로세스에 체계적이고 관리된 접근을 적용하는 일로 정의한다.[@iso-24089-obp-2023]

ISO 24089:2023은 1절 범위, 2절 인용 표준, 3절 용어와 정의 다음에 아래 본문 절을 둔다. 4절부터 9절까지는 각각 목적, 일반, 요구사항과 권고, 작업 산출물의 하위 절을 둔다.[@iso-24089-obp-2023]

| 절  | 제목                       |
| --- | -------------------------- |
| 4   | 조직 수준                  |
| 5   | 프로젝트 수준              |
| 6   | 인프라 수준                |
| 7   | 차량과 차량 시스템 수준    |
| 8   | 소프트웨어 업데이트 패키지 |
| 9   | 소프트웨어 업데이트 캠페인 |

### 용어

ISO 24089:2023은 **소프트웨어 업데이트 패키지**(software update package)를, 하나 이상의 차량, 차량 시스템, ECU에 배포하려는 소프트웨어와 그에 딸린 메타데이터의 묶음으로 정의한다. **소프트웨어 업데이트 캠페인**(software update campaign)은 대상을 식별하고 수신자를 정하는 일, 패키지를 배포하는 일, 소프트웨어 업데이트 작업의 결과를 모니터링하고 기록하는 일로 이어지는 순서다. 대상(target)은 차량 구성 정보로 정해지는 차량, 차량 시스템, ECU의 부류이고, 수신자(recipient)는 캠페인 중에 패키지를 받는 개별 차량, 차량 시스템, ECU다.[@iso-24089-obp-2023] 소프트웨어 업데이트 작업의 단계는 [[over-the-air-update#단계|OTA 업데이트의 단계]]에서 다룬다.

## UN R156과의 관계

R156 해석 문서는 ISO 24089:2023을 [[un-r156|UN R156]]의 [[software-update-management-system|SUMS]] 요구를 구현하는 데 도움이 되는 예시 표준으로 들고, R156의 문단과 ISO 24089:2023의 절을 표로 잇는다.[@unece-r156-interpretation-2025]
