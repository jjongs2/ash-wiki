**ISO 16845-1**은 [[iso-11898-1|ISO 11898-1]]이 표준화한 [[can|CAN]] 데이터 링크 계층과 물리 신호(physical signalling)의 적합성 시험 계획을 규정하는 국제 표준이다. 정식 제목은 "Road vehicles — Controller area network (CAN) conformance test plan — Part 1: Data link layer and physical signalling"이고, ISO/TC 22/SC 31이 맡는다.[@iso-16845-1-2016]

## 범위

ISO 16845-1:2016은 Classical CAN 프로토콜과 [[can-fd|CAN FD]] 프로토콜을 모두 시험 계획의 범위에 둔다. 날짜를 붙여 인용하는 규격은 ISO 11898-1:2015이고, [[osi-model|OSI]] 적합성 시험 방법론인 ISO/IEC 9646-1, -2, -4도 인용한다.[@iso-16845-1-obp-2016]

이 표준은 시험의 틀을 이루는 용어를 아래처럼 정의한다.

- **test plan**: OSI 적합성 시험 일반 개념 표준을 특정하게 적용한 것
- **test suite**: ISO 11898-1의 특정 파라미터에 대해 시험 대상의 동작을 확인하는 것
- **test type**: 시험 프레임의 방향을 정하는 것. 시험 대상이 메시지를 받는지, 보내는지, 둘 다인지가 그 예다.
- **test class**: test type마다 여덟 개로 나눈 것
- **lower tester**: test suite를 감독하는 쪽
- **upper tester**: 시험 대상의 사용자 역할을 하는 쪽[@iso-16845-1-obp-2016]

## 개정 이력

- 2004년: ISO 16845가 처음 나왔다. ISO 11898-1을 따르는 CAN 구현의 적합성을 확인하는 데 필요한 방법론과 추상 시험 묶음을 제공했다.[@iso-16845-1-obp-2016]
- 2016년: ISO 16845-1 첫판이 11월에 나왔다. 기술 개정을 거쳐 ISO 16845:2004를 대체했다.[@iso-16845-1-2016][@iso-16845-1-obp-2016]
- 2026년 10월 기준 ISO 16845-1:2016은 개정 대상이고, 다음 판이 ISO/DIS(Draft International Standard) 16845-1로 개발 중이다. 다음 판의 제목 끝은 "Data link layer and physical coding sublayer"다.[@iso-16845-1-2016][@iso-dis-16845-1-2026]
