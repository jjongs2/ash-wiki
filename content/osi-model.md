## 정의

**OSI 참조 모델**(Open Systems Interconnection Basic Reference Model)은 시스템 사이의 정보 교환을 다루는 개념적·기능적 틀이다. ITU-T X.200과 ISO/IEC 7498-1은 같은 본문으로 발행됐다. 참조 모델은 서비스와 프로토콜을 정하지 않고 구현 명세도 아니며, 표준 개발을 조율하는 공통 기반이자 서비스와 프로토콜을 정의할 때의 틀이 된다.[@itu-t-x-200-1994]

## 구조·동작

### 일곱 계층

참조 모델은 일곱 계층으로 이뤄지며, 아래에서부터 물리(1), 데이터 링크(2), 네트워크(3), 전송(4), 세션(5), 표현(6), 응용(7) 계층이다.[@itu-t-x-200-1994]

![[diagrams/osi-seven-layers.svg]]

- 물리 계층은 데이터 링크 개체 사이에서 비트를 전송하도록, 물리적 연결을 활성화하고 유지하고 해제하는 기계적·전기적·기능적·절차적 수단을 제공한다.[@itu-t-x-200-1994]
- 데이터 링크 계층은 네트워크 개체 사이의 데이터 링크 연결을 세우고 유지하고 해제하며, 물리 계층에서 생긴 오류를 검출하고 가능하면 정정한다.[@itu-t-x-200-1994]
- 네트워크 계층은 라우팅과 중계를 맡는다. 네트워크 주소 사이의 경로는 라우팅 기능이 정하므로, 전송 개체는 라우팅과 중계를 신경 쓰지 않아도 된다.[@itu-t-x-200-1994]
- 전송 계층은 세션 개체 사이의 투명한 데이터 전송을 제공하며, 전송 프로토콜은 종단 간에만 의미를 갖는다. 연결 모드에서 전송 계층의 기능에는 종단 간 [[segmentation-and-reassembly|분할]]과 흐름 제어가 들어갈 수 있다.[@itu-t-x-200-1994]
- 세션 계층은 표현 개체들이 대화를 조직하고 동기화하며 데이터 교환을 관리하는 수단을 제공한다.[@itu-t-x-200-1994]
- 표현 계층은 응용 개체가 주고받는 정보의 표현을 맡아, 응용 개체가 구문에 매이지 않게 한다.[@itu-t-x-200-1994]
- 응용 계층은 응용 프로세스가 OSI 환경에 접근하는 유일한 수단이다.[@itu-t-x-200-1994]

### 서비스와 프로토콜

맨 위 계층을 뺀 (N) 계층은 (N+1) 개체에 (N) 서비스를 제공한다. 이 서비스는 (N) 계층의 기능과, 필요하면 (N−1) 계층의 서비스로 만든다. 같은 계층의 (N) 개체끼리 어떻게 협력하는지는 (N) 프로토콜이 정한다.[@itu-t-x-200-1994]

![[diagrams/osi-service-protocol.svg]]

(N) 계층의 PDU(Protocol Data Unit)는 PCI(Protocol Control Information)와, 있으면 사용자 데이터로 이뤄진다. 분할이나 블로킹을 하지 않으면 위에서 넘어온 (N) SDU(Service Data Unit)에 (N) PCI를 붙여 (N) PDU를 만든다. (N) PDU는 (N−1) SDU에 일대일로 대응될 수 있지만, 다른 대응도 가능하다.[@itu-t-x-200-1994]

![[diagrams/osi-pdu-encapsulation.svg]]

## 비교·한계

[[can|CAN]]을 다루는 ISO 11898 시리즈는 데이터 링크 계층과 물리 계층을 규정한다.[@iso-11898-1-obp-2024] 그 가운데 ISO 11898-1:2024는 데이터 링크 계층을 LLC(Logical Link Control) 부계층과 MAC(Medium Access Control) 부계층으로 나눈다.[@iso-11898-1-2024] CAN 위의 전송 프로토콜과 네트워크 계층 서비스는 ISO 15765-2가 따로 규정한다.[@iso-15765-2-2024]
