## 정의

**SAE J1939**는 SAE International이 발행하는 차량 네트워크 권장 규격 모음으로, ECU끼리 통신하도록 개방형 표준 아키텍처를 준다. 온·오프로드 트럭과 트레일러, 건설기계, 농기계 등을 대상으로 한다.[@sae-j1939-21-2022] 트럭, 버스, 트랙터 같은 대형 차량의 데이터 통신에 쓰인다.[@sae-j1939dbc-2026]

J1939는 여러 하위 문서로 나뉜다. 최상위 문서 SAE J1939는 네트워크 전체의 개요와 하위 문서 구조를 설명하고, 하위 문서들이 함께 쓰는 용어와 약어를 정의한다.[@sae-j1939-2026]

## 구조·동작

### 데이터 링크 계층

J1939-21은 [[iso-11898-1|ISO 11898-1]]이 정한 [[can|CAN]]의 확장 프레임 포맷, 곧 29비트 [[can-identifier|식별자]]를 쓰는 데이터 링크 계층을 규정한다.[@sae-j1939-21-2022] [[can-fd|CAN FD]](CAN with Flexible Data-Rate)를 쓰는 데이터 링크 계층은 J1939-22가 따로 규정한다.[@sae-j1939-22-2022]

### 메시지와 신호

J1939에서는 메시지를 PGN(Parameter Group Number)으로, 메시지 안의 신호를 SPN(Suspect Parameter Number)으로 가리킨다. 엔진 회전수나 차속이 신호의 예다.[@sae-j1939dbc-2026]

애플리케이션 계층은 여러 J1939-7X 문서가 함께 정의한다. 그 가운데 J1939-71은 파라미터를 파라미터 그룹의 데이터 안에 배치하는 표기 규약과, 표준 데이터 인코딩(SLOT) 정의를 다룬다. 개별 파라미터와 파라미터 그룹의 정의는 이제 J1939DA(Digital Annex)에 실린다.[@sae-j1939-71-2025] J1939DA는 SPN마다 길이, 분해능, 오프셋, 데이터 범위, 단위 등을 싣는다.[@sae-j1939da-2017]

### 네트워크 관리

네트워크 관리 문서 J1939-81은 노드의 주소 선택과 주소 클레임 절차를 정한다.[@sae-j1939-81-2025]

### 물리 계층

J1939-11은 차폐 트위스트 페어를 쓰는 250 kbit/s 물리 계층을 규정한다.[@sae-j1939-11-2026] J1939-14는 J1939의 다른 물리 계층보다 대역폭이 큰 500 kbit/s 물리 계층을 규정한다.[@sae-j1939-14-2022]
