**J1939**는 SAE가 정한 대형 차량(heavy-duty vehicle)용 직렬 제어·통신 네트워크 규격 시리즈다.[@sae-j1939-2026] 트럭과 버스, 건설, 농업 용도로 함께 개발됐다.[@iso-11783-3-obp-2026] 도로와 비도로에서 쓰는 경·중·대형 차량이 대상이고, 트럭과 트레일러, 건설 장비, 농기계를 포함한다. J1939는 ECU끼리 통신하도록 표준 아키텍처를 준다.[@sae-j1939-21-2022]

## 데이터 링크 계층

J1939-21은 [[iso-11898-1|ISO 11898-1]]:2015의 [[can|CAN]] 확장 포맷 프레임과 29비트 [[can-identifier|식별자]]를 쓰는 데이터 링크 계층을 정한다.[@sae-j1939-21-2022] J1939-22는 ISO 11898-1:2015의 [[can-fd|CAN FD]]를 쓰는 데이터 링크 계층을 정한다.[@sae-j1939-22-2022]

농기계용 ISO 11783 시리즈는 일부가 J1939 시리즈를 바탕으로 한다. ISO 11783-3:2026은 CAN 확장 포맷 데이터 프레임보다 긴 메시지를 위한 전송 계층과 네트워크 계층 프로토콜을 J1939-21을 바탕으로 정한다.[@iso-11783-3-obp-2026]

ISO 11783-3:2026은 CAN 데이터 프레임 하나의 데이터 필드에 들어가지 않는, 8바이트가 넘는 메시지를 다중 패킷 메시지라고 한다.[@iso-11783-3-obp-2026] 다중 패킷 메시지는 한 PGN의 데이터를 CAN 데이터 프레임 여러 개에 나눠 보내고, 프레임마다 CAN 식별자는 같고 데이터는 다르다. 데이터 길이 $n$(바이트)이 $1786 \le n \le 117\,440\,512$인 파라미터 그룹은 확장 전송 프로토콜(ETP, Extended Transport Protocol)로 보낸다.[@iso-11783-1-obp-2017]

## 문서 구성

J1939는 문서 여럿으로 나뉜다. 최상위 문서는 J1939 네트워크를 개관하고, 하위 문서 구조와 하위 문서들이 함께 쓰는 용어와 약어를 정의한다.[@sae-j1939-2026] 하위 문서 가운데 몇 가지는 아래와 같다.

| 문서     | 계층          | 정하는 것                                                                                          |
| -------- | ------------- | -------------------------------------------------------------------------------------------------- |
| J1939-11 | 물리          | 250 kbit/s 차폐 꼬임쌍선 물리 계층[@sae-j1939-11-2026]                                             |
| J1939-14 | 물리          | 500 kbit/s 물리 계층. J1939의 다른 물리 계층보다 대역폭이 크다.[@sae-j1939-14-2022]                |
| J1939-15 | 물리          | 250 kbit/s 비차폐 꼬임쌍선 물리 계층[@sae-j1939-15-2018]                                           |
| J1939-21 | 데이터 링크   | CAN 확장 포맷 프레임을 쓰는 데이터 링크 계층[@sae-j1939-21-2022]                                   |
| J1939-22 | 데이터 링크   | CAN FD를 쓰는 데이터 링크 계층[@sae-j1939-22-2022]                                                 |
| J1939-31 | 네트워크      | 서로 다른 네트워크 세그먼트의 ECU를 잇는 네트워크 연결 ECU의 요구사항과 서비스[@sae-j1939-31-2023] |
| J1939-71 | 응용          | 파라미터와 파라미터 그룹의 정의, 배치와 전송 주기의 관례[@sae-j1939-71-2025]                       |
| J1939-81 | 네트워크 관리 | 애플리케이션의 주소를 관리하는 절차와 메시지[@sae-j1939-81-2025]                                   |

## 파라미터와 주소

J1939-71은 파라미터와 파라미터 그룹의 정의, 파라미터 그룹 데이터 안에 파라미터를 배치하는 관례, 파라미터 그룹의 전송 주기 관례를 다룬다. J1939-71에 실리던 파라미터와 파라미터 그룹의 정의는 이제 J1939DA(J1939 Digital Annex)에 실린다.[@sae-j1939-71-2025]

J1939-81은 J1939 네트워크에서 통신하는 애플리케이션의 주소를 관리하는 절차와 메시지를 정하고, 주소 선택과 주소 요구(address claiming) 절차를 정한다.[@sae-j1939-81-2025]

ISO 11783-1에서 PGN(Parameter Group Number)은 CAN 식별자의 EDP(Extended Data Page, 1비트), DP(Data Page, 1비트), PF(Protocol Data Unit Format, 8비트) 필드와 그룹 확장(GE, Group Extension)을 24비트로 나타낸 값이고, 파라미터 그룹 하나를 식별한다. 8비트 PS(Protocol Data Unit Specific) 필드는 목적지 주소이거나 GE다. 목적지 주소로 보내는 메시지에 쓰는 PDU1 포맷은 PS에 목적지 주소를 담고, PDU2 포맷은 PS에 GE를 담는다. 주소는 메시지의 송신지나 목적지를 정하는 8비트 필드이고, 제어 기능(CF, Control Function)마다 네트워크에서 고유한 주소 하나를 갖는다.[@iso-11783-1-obp-2017]

## NMEA 2000과의 관계

NMEA의 NMEA 2000 표준은 선박의 전자 장비를 잇는 CAN 기반 표준이다.[@nmea-2000-2026] CiA에 따르면 NMEA 2000도 J1939의 상위 계층 프로토콜과 프로파일을 받아들였다.[@cia-j1939-profile-family-2026]
