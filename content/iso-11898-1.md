**ISO 11898-1**은 [[can|CAN]]의 데이터 링크 계층과 물리 부호화 부계층(PCS, Physical Coding Sublayer)을 규정하는 국제 표준이다. 정식 제목은 "Road vehicles — Controller area network (CAN) — Part 1: Data link layer and physical coding sublayer"이고, ISO/TC 22/SC 31이 맡는다.[@iso-11898-1-2024]

CAN 프로토콜 컨트롤러를 구현하는 칩 설계자를 위한 표준이다.[@iso-11898-1-obp-2024] 이런 컨트롤러는 [[can-controller|CAN 컨트롤러]]에서 다룬다.

## 범위

ISO 11898-1:2024는 CAN CC(CAN classic), [[can-fd|CAN FD]], [[can-xl|CAN XL]] 세 프레임 포맷을 규정한다. 데이터 링크 계층을 LLC(Logical Link Control)와 MAC(Medium Access Control) 두 부계층으로 나눈다.[@iso-11898-1-2024]

이 표준은 구현 옵션 다섯 가지를 둔다.[@iso-11898-1-obp-2024]

1. CAN classic 프레임 포맷만 지원하고, CAN FD 프레임 포맷을 [[can-fd#호환성|용인]]하지 않는다.
2. CAN classic 프레임 포맷을 지원하고, CAN FD 프레임 포맷을 용인한다.
3. CAN classic 프레임 포맷과 CAN FD 프레임 포맷을 지원한다.
4. CAN classic, CAN FD, CAN XL 프레임 포맷을 지원한다.
5. [[can-fd-light|CAN FD light]]의 responder를 위해 CAN FD 프레임 포맷을 지원한다(Annex A).[@iso-11898-1-obp-2024]

이 표준의 옵션 4를 구현한 새 설계는 다른 모든 옵션의 노드와 통신할 수 있다.[@iso-11898-1-obp-2024] 옵션 사이의 통신 범위는 [[can-fd#호환성|CAN FD]]에서 다룬다.

이 표준은 LLC 프레임에 상위 계층 프로토콜의 설정·식별 정보를 담는 SDT(Service Data Unit Type)와 VCID(Virtual CAN Channel Identifier)를 두고, 상위 계층 기능을 어떻게 다루는지는 정하지 않는다.[@iso-11898-1-obp-2024]

이 표준은 [[can-physical-layer|물리 계층]]의 PCS가 AUI(Attachment Unit Interface)로 PMA(Physical Medium Attachment)와 이어지게 정하고, 정해진 개수의 [[can-bit-timing#Time quantum|time quantum]]으로 이뤄지는 비트 시간과 [[can-transceiver#FAST 모드|CAN SIC XL 트랜시버]]로 넘길 PWM(Pulse-Width Modulation) 부호화도 정한다.[@iso-11898-1-obp-2024]

[[iso-11898-2|ISO 11898-2:2026]]은 고속 CAN의 PMA를 규정하고, CAN_H와 CAN_L로 이뤄진 전기적 인터페이스를 MDI(Medium Dependent Interface)로 정의한다.[@iso-11898-2-obp-2026] [[iso-11898-3|ISO 11898-3:2006]]은 저속 내결함성 CAN의 MDI와 PMA를 규정한다.[@iso-11898-3-obp-2006] 버스 전압 같은 전기적 특성은 두 표준이 다룬다.[@iso-11898-2-obp-2026][@iso-11898-3-obp-2006]

![[diagrams/can-iso-11898-sublayers.svg]]

ISO 11898 시리즈는 데이터 링크 계층 위의 [[osi-model|OSI]] 계층(네트워크 계층 등)을 정하지 않는다.[@iso-11898-1-obp-2024] ISO 11898-1이 표준화한 데이터 링크 계층과 물리 신호의 적합성 시험 계획은 [[iso-16845-1|ISO 16845-1:2016]]이 정한다. 이 시험 계획은 Classical CAN과 CAN FD 프로토콜을 다루고, ISO 11898-1의 2015년판을 기준으로 한다.[@iso-16845-1-obp-2016]

## 개정 이력

- 1993년: ISO 11898이 11월에 처음 발행됐다.[@iso-11898-3-obp-2006] 이 한 문서가 CAN 데이터 링크 계층과 고속 물리 계층을 함께 다뤘다.[@iso-11898-1-obp-2015]
- 1995년: 4월에 1993년판의 추록 1(Amendment 1)이 나왔다. 새 소개를 넣고 본문 여러 쪽을 바꾸거나 더했다.[@iso-11898-amd-1-1995]
- 2003년: ISO 11898-1 첫판. ISO 11898-2와 함께 1993년판을 대체했다. 데이터 링크 계층과 물리 신호 부계층은 11898-1로, 고속 매체 접속 장치는 11898-2로 나뉘었다.[@iso-11898-1-obp-2003]
- 2015년: 2판. [[can-fd-frame|CAN FD 프레임]] 포맷이 새로 들어갔다. 제목 끝은 이 판까지 "Data link layer and physical signalling"이었고, 2024년판에서 "Data link layer and physical coding sublayer"로 바뀌었다.[@iso-11898-1-2024][@iso-11898-1-2015]
- 2024년: 3판. 2015년판을 대체했다. CAN XL 요구사항과 Annex A의 CAN FD light 프로토콜 요구사항이 더해졌고, 편집 정정이 있었다.[@iso-11898-1-obp-2024]

다른 부의 개정 이력은 [[iso-11898-2#개정 이력|ISO 11898-2]]와 [[iso-11898-3#개정 이력|ISO 11898-3]]에서 다룬다.

## Bosch CAN FD와의 차이

CAN FD는 Bosch가 2012년에 CAN FD Specification Version 1.0으로 먼저 공개했다.[@bosch-can-fd-1-0-2012] Bosch 규격의 CAN FD 프레임 포맷과 ISO 11898-1:2015의 CAN FD 프레임 포맷을 모두 지원하는 컨트롤러는 설정 비트로 둘 가운데 하나를 고른다.[@bosch-m-can-2023][@microchip-mcp25xxfd-frm-2020] Bosch M_CAN 매뉴얼은 이 설정 비트로 고르는 Bosch 규격 쪽 동작을 "**Non ISO Operation**"이라 부른다.[@bosch-m-can-2023] TI TCAN4550도 같은 설정 비트를 Non ISO Operation이라 부르고[@ti-tcan4550-2020], Microchip MCP25xxFD는 두 [[can-crc|CRC]] 필드를 ISO CRC와 non-ISO CRC로 구분한다.[@microchip-mcp25xxfd-frm-2020] CiA는 오해를 피하려고, ISO 11898-1을 따르는 CAN FD 제품은 "ISO CAN FD", Bosch의 원래 CAN FD 프로토콜을 구현한 제품은 "non-ISO CAN FD"라 부르기를 권한다.[@cia-iso-can-fd-or-non-iso-2014]

ISO 11898-1:2015는 프레임에서 CRC 필드 앞에 든 스터프 비트의 수(고정 스터프 비트 제외)를 [[can-bit-stuffing#CAN FD 프레임과의 차이|stuff bit count]]로 정의했고, ISO 11898-1:2024도 같은 정의를 둔다.[@iso-11898-1-obp-2024][@iso-11898-1-obp-2015] Bosch CAN FD 1.0은 CRC 필드를 CRC 시퀀스와 그 뒤의 recessive CRC 구분자 비트로 정한다.[@bosch-can-fd-1-0-2012] ISO CRC 필드에 싣는 스터프 개수는 Bosch CAN FD 1.0에 없던 것으로, ISO 표준화 과정에서 오류 검출을 보강하려고 더해졌다.[@microchip-mcp25xxfd-frm-2020][@bosch-icc-can-fd-error-detection-2015]
