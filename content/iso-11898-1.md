## 정의

ISO 11898-1은 [[can|CAN]]의 데이터 링크 계층과 물리 부호화 부계층(PCS, Physical Coding Sublayer)을 규정하는 국제 표준이다. 정식 제목은 "Road vehicles — Controller area network (CAN) — Part 1: Data link layer and physical coding sublayer"이고, ISO/TC 22/SC 31이 맡는다.[@iso-11898-1-2024]

CAN 프로토콜 컨트롤러를 구현하는 칩 설계자를 위한 표준이다.[@iso-11898-1-obp-2024] 이런 컨트롤러는 [[can-controller|CAN 컨트롤러]]에서 다룬다.

## 범위

현행 2024년판은 classic CAN, CAN FD(CAN with Flexible Data-Rate), CAN XL 세 프레임 포맷을 규정한다. 데이터 링크 계층을 LLC(Logical Link Control)와 MAC(Medium Access Control) 두 부계층으로 나눈다.[@iso-11898-1-2024]

PCS는 물리 계층에 속하는 부계층이고, PMA(Physical Medium Attachment)와는 AUI(Attachment Unit Interface)로 이어진다.[@iso-11898-1-obp-2024] PCS는 비트 부호화·복호화와 동기화를 맡는다.[@iso-11898-2-obp-2026] 한 비트의 시간도 이 표준이 정하는데, 정해진 개수의 time quantum으로 이뤄진다.[@iso-11898-1-obp-2024]

PMA는 이 표준의 범위 밖이다. 고속 PMA는 [[iso-11898-2|ISO 11898-2]]가, 저속 내결함성 PMA는 [[iso-11898-3|ISO 11898-3]]이 규정한다.[@iso-11898-1-obp-2015]

## 개정 이력

- 1993년: ISO 11898 한 문서가 CAN 데이터 링크 계층과 고속 물리 계층을 함께 다뤘다.[@iso-11898-1-obp-2015]
- 2003년: ISO 11898-1 첫판. ISO 11898-2와 함께 1993년판을 대체했다. 데이터 링크 계층과 물리 신호 부계층은 11898-1로, 고속 매체 접속 장치는 11898-2로 나뉘었다.[@iso-11898-1-obp-2003]
- 2015년: 2판. CAN FD 프레임 포맷이 새로 들어갔다. 제목 끝은 이 판까지 "Data link layer and physical signalling"이었다.[@iso-11898-1-2015]
- 2024년: 3판. CAN XL 요구사항이 더해졌다.[@iso-11898-1-obp-2024]

## Bosch CAN FD와의 차이

CAN FD는 Bosch가 2012년에 CAN FD Specification Version 1.0으로 먼저 공개했다.[@bosch-can-fd-1-0-2012] ISO 11898-1:2015의 CAN FD 프레임 포맷은 Bosch 규격과 달라, 두 포맷을 모두 지원하는 컨트롤러는 설정 비트로 하나를 고른다. Bosch M_CAN 매뉴얼은 이 설정 비트로 고르는 Bosch 규격 쪽 동작을 "Non ISO Operation"이라 부른다.[@bosch-m-can-2023]

차이 가운데 하나로, ISO 11898-1:2015를 따르는 CAN FD는 CRC(Cyclic Redundancy Check) 필드에 스터프 비트 개수를 넣는다. Bosch 규격에는 없던 값이다.[@microchip-mcp25xxfd-frm-2020]
