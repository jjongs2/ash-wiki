**ISO 11898-1**은 [[can|CAN]]의 데이터 링크 계층과 물리 부호화 부계층(PCS, Physical Coding Sublayer)을 규정하는 국제 표준이다. 정식 제목은 "Road vehicles — Controller area network (CAN) — Part 1: Data link layer and physical coding sublayer"이고, ISO/TC 22/SC 31이 맡는다.[@iso-11898-1-2024]

CAN 프로토콜 컨트롤러를 구현하는 칩 설계자를 위한 표준이다.[@iso-11898-1-obp-2024] 이런 컨트롤러는 [[can-controller|CAN 컨트롤러]]에서 다룬다.

## 범위

ISO 11898-1:2024는 classical CAN, [[can-fd|CAN FD]], CAN XL 세 프레임 포맷을 규정한다. 데이터 링크 계층을 LLC(Logical Link Control)와 MAC(Medium Access Control) 두 부계층으로 나눈다.[@iso-11898-1-2024]

PCS는 [[can-physical-layer|물리 계층]]에 속하는 부계층이고, PMA(Physical Medium Attachment)와는 AUI(Attachment Unit Interface)로 이어진다.[@iso-11898-1-obp-2024] PCS는 비트 부호화·복호화와 [[can-synchronization|동기화]]를 맡는다.[@iso-11898-2-obp-2026] 한 비트의 시간도 이 표준이 정하는데, 정해진 개수의 [[can-bit-timing#Time quantum|time quantum]]으로 이뤄진다.[@iso-11898-1-obp-2024]

고속 PMA는 [[iso-11898-2|ISO 11898-2:2026]]이, 저속 내결함성 PMA는 [[iso-11898-3|ISO 11898-3:2006]]이 규정하고, 버스 전압 같은 전기적 특성도 두 표준이 다룬다.[@iso-11898-2-obp-2026][@iso-11898-3-obp-2006]

## 개정 이력

- 1993년: ISO 11898이 11월에 처음 발행됐다.[@iso-11898-3-obp-2006] 이 한 문서가 CAN 데이터 링크 계층과 고속 물리 계층을 함께 다뤘다.[@iso-11898-1-obp-2015]
- 2003년: ISO 11898-1 첫판. ISO 11898-2와 함께 1993년판을 대체했다. 데이터 링크 계층과 물리 신호 부계층은 11898-1로, 고속 매체 접속 장치는 11898-2로 나뉘었다.[@iso-11898-1-obp-2003]
- 2015년: 2판. [[can-fd-frame|CAN FD 프레임]] 포맷이 새로 들어갔다. 제목 끝은 이 판까지 "Data link layer and physical signalling"이었고, 2024년판에서 "Data link layer and physical coding sublayer"로 바뀌었다.[@iso-11898-1-2024][@iso-11898-1-2015]
- 2024년: 3판. CAN XL 요구사항이 더해졌다.[@iso-11898-1-obp-2024]

## Bosch CAN FD와의 차이

CAN FD는 Bosch가 2012년에 CAN FD Specification Version 1.0으로 먼저 공개했다.[@bosch-can-fd-1-0-2012] ISO 11898-1:2015의 CAN FD 프레임 포맷은 Bosch 규격과 달라, 두 포맷을 모두 지원하는 컨트롤러는 설정 비트로 하나를 고른다. Bosch M_CAN 매뉴얼은 이 설정 비트로 고르는 Bosch 규격 쪽 동작을 "**Non ISO Operation**"이라 부른다.[@bosch-m-can-2023] TI TCAN4550도 같은 설정 비트를 Non ISO Operation이라 부르고[@ti-tcan4550-2020], Microchip MCP25xxFD는 두 CRC 필드를 ISO CRC와 non-ISO CRC로 구분한다.[@microchip-mcp25xxfd-frm-2020] CiA는 오해를 피하려고, ISO 11898-1을 따르는 CAN FD 제품은 "ISO CAN FD", Bosch의 원래 CAN FD 프로토콜을 구현한 제품은 "non-ISO CAN FD"라 부르기를 권한다.[@cia-iso-can-fd-or-non-iso-2014]

차이 가운데 하나로, ISO 11898-1:2015를 따르는 CAN FD는 [[can-crc|CRC]] 필드에 [[can-bit-stuffing|스터프 비트]] 개수를 넣는다. Bosch 규격에는 없던 값이다.[@microchip-mcp25xxfd-frm-2020]
