# 검토 브리프

[소식 조사](SKILL.md)의 [8. 검토](SKILL.md#8-검토)를 맡은 검토 에이전트용 브리프다. 한 주차의 호를 맡아, 소식 항목마다 원문을 다시 열고 아래 체크리스트로 판정한다. 판정의 규칙은 SKILL.md와 `docs/weekly-news.md`에 있고, 체크리스트는 그 규칙을 가리킨다.

## 부르는 쪽이 알려 주는 값

- 주차와 그 주의 월요일·일요일
- 그 주의 기계 검사 출력(위키 링크 후보)
- 작업 폴더(절대 경로)

## 먼저 읽는다

1. [SKILL.md](SKILL.md)의 3단계 첫 문단(범위)과 4\~7단계
2. `docs/weekly-news.md`(형식, 필드 표, 이전 호 항목 링크)
3. `docs/source-access.md`(호스트별 여는 법)
4. 작업 폴더의 `past.tsv`(지난 호)와 `merged.jsonl`(조사 에이전트의 후보와 근거)

## 체크리스트

`content/news/<주차>.md`의 소식 항목마다, 원문을 직접 열어 아래 항목을 하나씩 통과나 실패로 판정한다.

| 항목        | 통과 조건                                                                                                                                       | 규칙                                                           |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| 필드        | 원어 제목이 원문 제목 그대로이고, 매체 이름, 발행일, 이미지가 규칙대로다                                                                        | `docs/weekly-news.md` 필드 표, [매체 목록의 열](outlets.md#열) |
| 싣기        | 범위 안이고, 기간, 1차 발표 우선, 유료 원문, 광고성 기사, 루머 기준을 지난다. 제3자 기사면 1차 발표를 직접 찾아본다                             | SKILL.md 3단계 첫 문단, 4단계                                  |
| 문턱        | 제품·인증 발표면 문턱 조건 하나가 원문에 있다. 문턱의 대상이 아닌 원문(4단계 문턱의 끝 문단)은 통과다                                           | 4단계의 제품·인증 발표 문턱                                    |
| 중복        | 지난 호(`past.tsv`)나 이 호의 다른 항목과 같은 사건이 아니거나, 같은 사건이면 새 진전을 요약에서 말하고 이전 호 항목에 링크한다                 | 5단계                                                          |
| 주요        | `주요` 필드가 있는 항목은 기준 번호와 그 주의 사건을 댈 수 있고, 없는 항목은 기준에 들지 않는다. 리콜은 [recall.py](recall.py)로 센 값으로 본다 | 6단계                                                          |
| 한국어 제목 | 원어 제목이 한국어가 아닌 주요 소식에만 있고, 원어 제목과 원문에 대어 뜻이 맞으며, 주어와 사건이 드러난다. 원문에 없는 것을 더하지 않았다       | 7단계                                                          |
| 구역        | 7단계의 구역 규칙대로다                                                                                                                         | `docs/weekly-news.md` 필드 표, 7단계                           |
| 요약의 꼴   | 길이가 7단계의 목표 안팎이고, 원문 본문에 적힌 것으로만 자기 말로 썼다. 원문에 없는 날짜, 수치, 최상급, 거쳐 온 기사의 문장이 없다              | 7단계                                                          |
| 위키 링크   | 기계 검사의 위키 링크 후보마다, 그 개념을 가리키면 호 안 첫 등장에 링크가 있고, 가리키지 않으면 링크가 없다                                     | 7단계                                                          |

## 실패를 다루는 법

- 고칠 수 있는 실패는 호 파일에서 고친다. 1차 발표를 찾았으면 그것으로 바꾸고 제목, URL, 매체, 발행일, 이미지, 한국어 제목, 요약을 새 원문에 맞춰 다시 쓴다. `주요` 필드를 빼거나 달면 `한국어 제목`도 함께 빼거나 단다.
- 싣기와 문턱의 실패, 새 진전이 없는 중복은 항목을 호 파일에서 뺀다.
- 규칙을 원문에 대어도 통과와 실패가 갈리거나(규칙이 두 가지로 읽히는 등), 원문이 열리지 않아 고치지 못한 것은 고치지 않고 소유자 확인으로 올린다.
- 맡은 주차의 호 파일 말고는 고치지 않는다.

## 출력

작업 폴더의 `review/<주차>.jsonl`에 소식 항목마다 한 줄을 쓴다. 뺀 항목도 쓴다.

<!-- prettier-ignore -->
```jsonl
{"title":"고친 뒤 원어 제목","url":"고친 뒤 원문 URL","from":"","result":"고침","failed":["요약의 꼴"],"major":"","reason":"요약의 '처음'이 원문에 없어 뺐다"}
```

| 필드           | 값                                                                                          |
| -------------- | ------------------------------------------------------------------------------------------- |
| `title`, `url` | 검토를 마친 뒤의 원어 제목과 원문 URL. 뺀 항목은 뺄 때의 값                                 |
| `from`         | 원문을 바꿨으면 바꾸기 전 URL, 아니면 빈 문자열                                             |
| `result`       | `통과`, `고침`, `뺌`, `소유자 확인` 가운데 하나                                             |
| `failed`       | 실패한 체크리스트 항목 이름                                                                 |
| `major`        | `주요` 필드가 있는 항목의 기준 번호와 사건(예: `2: 26V213 리콜, 12만 대`). 없으면 빈 문자열 |
| `reason`       | 고친 것, 뺀 이유. 소유자 확인이면 쟁점과 권고                                               |

마지막 응답에는 결과별 항목 수, 뺀 항목과 이유, 소유자 확인 항목과 권고만 짧게 적는다.

## 주의

- 요청 간격, User-Agent, 여는 순서, 브라우저 쓰는 법은 [outlets.md의 접속 절](outlets.md#접속)을 따른다.
- 셸 명령이 복잡하다고 거부되면 파이썬 스크립트를 작업 폴더의 `review/<주차>-tmp/`에 써서 `python3 -I <경로>`로 돌린다.
- 확인하지 못한 값은 지어내지 않는다.
