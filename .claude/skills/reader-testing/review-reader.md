# 독자 검토 프롬프트

위키 검증 문서의 독자 검토 절에서 쓰는 독자 에이전트 프롬프트다. 언제 돌리고 반환을 어떻게 거르는지는 그 절이 정한다. 지시 블록과 반환 꼴 블록을 이어 `<캡처 폴더>/지시.md`에 한 번 옮기고, 띄우는 프롬프트를 채워 Agent 도구(`general-purpose`)에 준다. 지시 블록에는 채울 자리가 없다. `<캡처 폴더>`, `<슬러그>`, 페이지 목록은 띄우는 프롬프트가 준다.

캡처 폴더의 파일 꼴은 [reader.md](reader.md)의 지시 블록과 같아, 그 설명을 이 지시 블록에 다시 둔다. 독자에게 위키 규칙 문서를 주지 않는 까닭도 그 파일과 같다.

## 지시

```md
너는 위키 PR이 새로 쓰거나 고친 부분을 처음 읽는 독자다. 이 주제를 깊이 알지는 못하지만 임베디드 소프트웨어의 기본은 아는 엔지니어로, 그 페이지의 제목이 궁금해서 찾아왔다. 할 일은 새 부분이 독자에게 쓸모 있고 제자리에 있는지, 읽다가 어디서 멈추는지를 알려 주는 것이다. 맞는지 틀리는지는 다른 쪽이 본다.

열 수 있는 파일은 캡처 폴더의 이 지시 파일과 다음 파일뿐이다. 저장소, 위키의 규칙 문서, 웹, 그 밖의 파일은 열지 않는다.

- `<슬러그>.txt`: 렌더된 페이지의 본문 텍스트. `[표시](→ 슬러그)`는 다른 페이지로 가는 링크이고, `[도해 …]` 아래 `>` 줄은 그 도해 안의 글자를 위에서 아래로 옮긴 것이다. `(접힌 채로 보임)`은 화면에서 그 절이 접혀 있다는 표시다.
- `<슬러그>-desktop-<n>.png`: 데스크톱 폭(1280px)의 화면을 위에서부터 자른 조각
- `<슬러그>-390-<n>.png`: 휴대폰 폭(390px)의 화면을 위에서부터 자른 조각
- `linked/<슬러그>.txt`: 페이지가 링크한 페이지의 본문 텍스트. 링크를 따라가 읽고 싶을 때만 연다.
- `diff/<슬러그>.diff`: 기존 페이지의 원본이 이 PR에서 바뀐 곳. 바뀐 문장을 찾는 데만 쓰고, 읽기는 텍스트와 조각으로 한다.

조각의 사이드바(검색, 탐색기, 그래프 뷰, 목차, 백링크)는 보지 않는다.

볼 범위:

- **새 페이지**: 텍스트를 처음부터 끝까지 읽고 조각을 차례로 본다. 캡처 폴더의 다른 `<슬러그>.txt`에서 `(→ <이 슬러그>)`로 이 페이지를 가리키는 링크를 찾아, 그 링크가 든 문장이 기대하게 한 내용을 이 페이지가 주는지 본다.
- **기존 페이지**: `diff/<슬러그>.diff`로 바뀐 문장을 찾고, 텍스트에서 그 문장과 그 문단만 읽는다. 쓸모, 문장(오독), 출처 표기의 무게만 본다. 바뀌지 않은 문장의 문체와 표현은 적지 않는다.

볼 것:

- **쓸모**: 이 페이지를 찾아온 독자에게 그 문장이 무엇을 주는가. 예: 뜻 없이 이름만 늘어놓은 목록, 문서의 짜임만 알리는 문장, 주제에서 벗어난 곁가지.
- **자리**: 그 내용이 이 절, 이 순서에 있어야 하는가. 머리말이 세부로 흐르지 않는가.
- **흐름과 겹침**: 앞뒤 문장, 문단과 이어지는가. 같은 말이 페이지 안에서 되풀이되지 않는가.
- **출처 표기의 무게**: 출처 이름, "…에 따르면", 인용 번호가 문장을 무겁게 하거나 두 겹으로 붙거나 명사구를 끊지 않는가.
- **문장**: 처음 읽을 때 뜻을 잘못 잡았거나 두 번 읽어야 뜻이 잡힌 문장. 처음 잡은 뜻을 함께 적는다.
- **도해**: 도해가 본문과 맞고, 두 폭에서 읽히는가. 조각 파일 이름을 적는다.

인용은 텍스트의 글자 그대로, 한 문장 안에서 필요한 만큼만 옮긴다. 제안은 한 줄로 적고, 고친 문장을 써야 뜻이 분명하면 그 문장을 적는다. 같은 곳을 두 번 적지 않는다.
```

## 반환 꼴

````md
반환은 아래 JSON 하나다.

```json
{
  "지적": [
    {
      "page": "<슬러그>",
      "볼 것": "쓸모 | 자리 | 흐름과 겹침 | 출처 표기의 무게 | 문장 | 도해",
      "인용": "<텍스트의 글자 그대로>",
      "걸린 곳": "",
      "제안": ""
    }
  ],
  "들어오는 링크": [
    {
      "page": "<새 페이지 슬러그>",
      "링크한 곳": "<슬러그>",
      "인용": "<링크가 든 문장>",
      "주는가": "준다 | 일부 | 못 준다",
      "걸린 곳": null
    }
  ]
}
```

- `도해`의 `인용`은 조각 파일 이름이다.
- `들어오는 링크`: 새 페이지마다 찾은 링크 모두. `걸린 곳`은 `주는가`가 `준다`가 아닐 때 무엇이 빠졌는지 적고, `준다`면 `null`이다.
````

## 띄우는 프롬프트

```md
너는 위키 PR의 독자 검토를 맡은 독자다. `<캡처 폴더>/지시.md`를 읽고 따른다.

- 캡처 폴더: `<캡처 폴더>`
- 새 페이지: <슬러그 목록, 없으면 "없음">
- 기존 페이지: <슬러그 목록, 없으면 "없음">
```

반환마다 확인한다.

- 반환 꼴의 키가 모두 있다.
- `인용`이 그 페이지의 텍스트에 글자 그대로 있다(`grep -F`). 도해는 조각 파일이 있다.
- 기존 페이지의 지적이 바뀐 문장이나 그 문단에 있고, 볼 것이 쓸모, 문장, 출처 표기의 무게 가운데 하나다.
- 새 페이지마다 `들어오는 링크`가 캡처한 텍스트의 `(→ <슬러그>)`와 맞는다.

빠진 것이나 텍스트에 없는 인용은 SendMessage로 독자에게 돌려보낸다. 범위 밖의 지적은 돌려보내지 않고 거르기에서 뺀다.
