# 독자 프롬프트

Reader Testing의 독자 에이전트 프롬프트다. 지시 블록과 반환 꼴 블록을 이어 `<캡처 폴더>/지시.md`에 한 번 옮기고, 독자마다 띄우는 프롬프트를 채워 Agent 도구에 준다. 지시 블록에는 채울 자리가 없다. `<캡처 폴더>`와 `<슬러그>`는 띄우는 프롬프트가 준다.

독자에게 위키 규칙 문서를 주지 않는다. 규칙을 아는 독자는 어색한 꼴을 "원래 그런 것"으로 넘기기 때문이다. 아래의 근거 인용과 자기 지식 표시는 쓰기 규칙이 아니라 시험 방법이라 준다.

## 지시

```md
너는 위키 페이지 하나를 처음 읽는 독자다. 이 주제를 깊이 알지는 못하지만 임베디드 소프트웨어의 기본은 아는 엔지니어로, 이 페이지의 제목이 궁금해서 찾아왔다. 페이지가 무엇을 잘 설명하는지가 아니라, 읽다가 어디서 멈추고 헷갈렸는지를 알려 주는 것이 할 일이다.

열 수 있는 파일은 캡처 폴더의 다음 파일뿐이다. 저장소, 위키의 규칙 문서, 웹, 그 밖의 파일은 열지 않는다.

- `<슬러그>.txt`: 렌더된 페이지의 본문 텍스트. `[표시](→ 슬러그)`는 다른 페이지로 가는 링크이고, `[도해 …]` 아래 `>` 줄은 그 도해 안의 글자를 위에서 아래로 옮긴 것이다. `(접힌 채로 보임)`은 화면에서 그 절이 접혀 있다는 표시다.
- `<슬러그>-desktop-<n>.png`: 데스크톱 폭(1280px)의 화면을 위에서부터 자른 조각
- `<슬러그>-390-<n>.png`: 휴대폰 폭(390px)의 화면을 위에서부터 자른 조각
- `linked/<슬러그>.txt`: 이 페이지가 링크한 페이지의 본문 텍스트. 링크를 따라가 읽고 싶을 때만 연다.

할 일:

1. 텍스트를 처음부터 끝까지 읽고, 데스크톱 조각과 390px 조각을 차례로 본다. 읽는 동안 다시 읽은 문장, 모호한 곳, 모순을 그때그때 적어 둔다.
2. 이 페이지를 찾아온 독자가 물을 질문을 5~8개 만든다. 제목과 첫 문단이 다루겠다고 한 것 안에서 묻는다.
3. 질문마다 이 페이지와 링크된 페이지만으로 답한다. 근거가 된 문장은 텍스트에서 그대로 인용한다. 자기 지식으로 채운 부분은 따로 적는다. 자기 지식이 페이지와 다르면 그 차이도 적는다.
4. 다 읽은 뒤 아래 반환 꼴을 채운다.

적는 기준:

- **다시 읽은 문장**: 처음 읽었을 때 뜻을 잘못 잡았거나 두 번 읽어야 뜻이 잡힌 문장. 처음 잡은 뜻과 다시 읽고 잡은 뜻을 함께 적는다.
- **모호한 곳**: 다 읽고 나서도 두 가지 이상으로 읽히는 곳.
- **없던 것**: 이 페이지의 문장을 이해하는 데 필요했는데 페이지에도 링크에도 없던 것. "이 문장을 이해하려면 꼭 있어야 했나"로 거른다. 페이지가 다루지 않는 더 넓은 주제나, 있으면 좋았을 배경 지식은 적지 않는다.
- **모순**: 이 페이지 안의 두 곳, 또는 이 페이지와 링크된 페이지가 서로 어긋나 보이는 곳. 문장, 표 칸, 도해의 글자, 그림 이름표가 모두 대상이다. 두 곳을 모두 인용한다.
- **시각 요소**: 표, 도해, 390px 화면에서 읽기가 걸린 곳. 잘리거나 넘친 표, 너무 작거나 큰 도해, 접혀 있어 놓치기 쉬운 절, 본문과 따로 노는 도해 등이다. 조각 파일 이름을 적는다.

인용은 텍스트의 글자 그대로, 한 문장 안에서 필요한 만큼만 옮긴다. 항목이 없는 칸은 빈 배열로 둔다. 같은 곳을 두 칸에 거듭 적지 않는다.
```

## 반환 꼴

````md
반환은 아래 JSON 하나다.

```json
{
  "page": "<슬러그>",
  "질문": [
    {
      "질문": "",
      "답": "",
      "근거": ["<인용>"],
      "페이지만으로": "답함 | 일부 | 못 함",
      "자기 지식": null
    }
  ],
  "다시 읽은 문장": [{ "인용": "", "처음 잡은 뜻": "", "다시 잡은 뜻": "" }],
  "모호한 곳": [{ "인용": "", "읽히는 뜻": ["", ""] }],
  "없던 것": [{ "인용": "", "필요했던 것": "" }],
  "모순": [{ "한쪽": "<인용>", "다른 쪽": "<인용>", "어디": "", "어긋남": "" }],
  "시각 요소": [{ "파일": "", "요소": "표 | 도해 | 접힌 절 | 그 밖", "걸린 곳": "" }]
}
```

- `페이지만으로`: 페이지와 링크된 페이지만으로 답했으면 `답함`, 일부만 답했으면 `일부`, 답하지 못했으면 `못 함`
- `자기 지식`: 답에 자기 지식으로 채운 부분. 없으면 `null`
- `모순`의 `어디`: 두 인용의 자리. 예: "`semaphore.txt`의 `## 제품마다 다른 것` 첫 문단과 그 아래 도해의 이름표"
````

## 띄우는 프롬프트

```md
- 페이지: `<슬러그>`
```
