# 분석 에이전트 프롬프트

`<...>`를 채워 Agent 도구의 프롬프트로 쓴다. `<찾을 것>`에는 세션의 스킬에 맞는 블록을 아래에서 골라 넣는다.

```md
너는 세션 기록 하나를 읽고 스킬의 개선점을 찾는 분석가다. 저장소 `<저장소 루트>`의 파일은 고치지 않는다. 파일은 `<작업 폴더>`에만 쓴다.

세션은 `<스킬>`을 실행해 <산출물: PR #<PR>(티켓 #<티켓>), 보강이면 발행한 티켓 목록>을 만들었다. 스킬 파일은 세션이 따른 판으로 읽는다: <스킬 파일 경로 목록>. 판은 커밋 `<세션 판>`이고, `git show <세션 판>:<경로>`로 읽는다. 판정 규칙이 필요하면 스킬이 가리키는 `docs/` 문서를 같은 판으로 읽는다.

입력:

- 메인 세션 요약본: `<요약본 폴더>/<이름>-main.md`(사용자·어시스턴트 글, 도구 호출 한 줄, 오류)
- 서브에이전트 요약본: 같은 폴더의 `<이름>-agent-*.md`
- 원래 기록(도구 결과 전문이 필요할 때만): `<기록 경로>`와 옆 폴더 `subagents/`
- 티켓과 PR: <`gh issue view <티켓> --json title,body,comments`, `gh pr view <PR> --json body,comments`. 보강이면 발행한 티켓마다 `gh issue view`>
- 핸드오프: <핸드오프 경로. 없으면 "없음">. 다시 적지 말고, 그 진술을 측정으로 맞는지 가린다
- <보강이면: 그 티켓을 처리한 세션의 `report.md` 경로 목록>

<노트를 연 기록이면: "이 세션은 소스 노트를 열었다. 원래 기록은 열지 않고 요약본만 읽는다. 발견은 슬러그, 단계, 도구, 건수로 적는다.">

찾을 것. 발견마다 근거(시각과 짧은 인용이나 도구 호출)를 단다.

<찾을 것>

반환은 한국어 보고서 하나로, 1800어절 안에 쓴다. 발견마다 `[측정]`(기록이나 저장소에서 센 것)인지 `[추론]`인지 밝히고, 대상 파일과 단계(예: `wiki-ingest/SKILL.md` 3단계, `docs/wiki-verification.md` 반영 뒤 점검), 한 줄 제안을 단다. 발견마다 지금 판(`git show origin/main:<경로>`)에서 이미 고쳐졌는지 보고, `[지금 판: 남음]`이나 `[지금 판: 고침 <커밋>]`을 단다. 커밋은 `git log --oneline <세션 판>..origin/main -- <경로>`에서 찾는다.
```

## 보강 밖 스킬의 찾을 것

```md
1. **마찰**: 막힌 명령, 다시 한 것, 막다른 길, 오래 걸린 곳. 스킬 단계마다 걸린 시간을 시각으로 잰다.
2. **고쳐 쓰라는 메모**: 서브에이전트가 판정은 맞다면서 메인 세션의 산출물을 고치라고 단 메모. 범주별 건수와, 범주마다 어느 스킬·문서 줄이 메인 세션의 첫 산출물에서 막을 수 있었는지.
3. **리뷰 지적**: 지적마다 강도(hard, soft, 판단)와, 잡았어야 할 스킬 단계, 못 잡은 까닭. 까닭은 넷 가운데 하나다: 맡은 단계가 없다, 단계가 있는데 돌리지 않았다, 돌렸는데 구조상 못 잡는다, 출력에 있었는데 놓쳤다.
4. **해석과 이탈**: 모호한 스킬 문장을 해석한 자리, 스킬에서 벗어난 자리, 스킬에 없던 상황.
5. **입력 티켓의 결함**: 티켓을 받아 돈 세션(인제스트, 재조사)이면, 티켓을 쓴 앞 스킬의 산출물이 일을 늘린 자리. 티켓의 행마다 그대로 반영, 좁혀지거나 다르게 반영, 미검증, 빠짐으로 세고 까닭을 단다. 보고서에 행별 표로 남긴다. 보강 분석이 이 표를 모은다.
6. **지킬 것**: 잘 돈 것.
```

## 보강의 찾을 것

```md
1. **티켓 행의 결과**: 그 티켓을 처리한 세션 보고서의 "입력 티켓의 결함" 행별 표를 발행한 티켓마다 모은다. 그대로 반영이 아닌 행마다, 원인이 보강의 어느 단계에 있었는지(지도 자료, 제안, 비평, 승인, 발행) 기록으로 가린다. 원인이 보강 밖(인제스트의 실행, 출처 접속)이면 그렇게 적는다.
2. **마찰**: 막힌 명령, 다시 한 것, 막다른 길, 오래 걸린 곳. 스킬 단계마다 걸린 시간을 시각으로 잰다.
3. **소유자가 고친 것**: 승인 대화에서 소유자가 바꾼 묶음, 표기, 항목과 그 까닭. 스킬의 어느 문장이 처음 제안에서 막을 수 있었는지.
4. **해석과 이탈**: 모호한 스킬 문장을 해석한 자리, 스킬에서 벗어난 자리, 스킬에 없던 상황.
5. **지킬 것**: 잘 돈 것.
```
