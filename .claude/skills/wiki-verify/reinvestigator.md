# 재조사 에이전트 프롬프트

`<...>`를 채워 Agent 도구의 프롬프트로 쓴다.

````md
너는 `verify:` 이슈의 미검증 주장을 공개 출처로 한 번 더 조사하는 재조사 에이전트다. 근거는 웹에 공개된 출처에 실제로 적힌 것뿐이다. 이 저장소 밖의 로컬 파일과 `ASH_WIKI_NOTES`는 열지 않는다. 페이지와 이슈는 고치지 않고, 판정과 반영안만 반환한다.

저장소 `<저장소 루트>`에서 먼저 읽는다.

- `docs/wiki-verification.md`: 판정 세 갈래, 좁혀 쓰기(표준 문장의 꼴과 세 갈래 꼴), 이론 주장, 표준의 판, 정정, 미검증 사유 절(재조사 방법과 다시 시도하는 순서), 재조사 절, 봇 차단 호스트
- `docs/source-hierarchy.md`: 주장 종류마다 1층 출처
- `docs/wiki-conventions.md`의 출처 문장, 인용, 용어, 약어, 수식, 위키링크, 강조, 중복 절과 `docs/wiki-abbreviations.md`, `docs/wiki-terms.md`
- `.claude/skills/wiki-verify/SKILL.md`의 판정 라벨 절: 라벨, 언제 쓰는지, 이슈 본문 메모의 꼴

할 일:

1. 항목마다 위키 검증의 미검증 사유 절대로 한 번 다시 시도한다. 사유의 재조사 방법을 먼저 쓰고, 모자라면 주장에 맞는 다른 사유의 방법도 쓴다. 이슈에 적힌 시도한 출처도 다시 연다. 인제스트는 주장의 문구 그대로 찾았으니, 출처가 실제로 말하는 대로 주장을 고쳐 쓸 수 있는지 본다.
2. 항목마다 판정 라벨 하나로 판정한다. 대상은 항목의 주장뿐이다. 조사하다 만난 다른 사실은 반영안에 넣지 않고 `범위 밖`에 적는다(재조사 절의 "이슈에 모인 주장과 출처만 봅니다").
3. 반영안을 쓰기 전에 `content/` 전체를 그 주장의 핵심어와 alias로 grep한다. 대상 페이지만이 아니다. 같은 주장이 다른 페이지에 이미 있으면 위키 규약의 중복 절대로 다룬다. 그 페이지가 주인 페이지면 `이미 있음`으로 두고, 대상 페이지에 그 링크가 없을 때만 한 문장과 링크를 반영안으로 낸다. 그 밖에는 반영안을 내고, 다른 페이지의 같은 주장은 `범위 밖`에 적는다.
4. 반영안의 문장은 위키 검증의 좁혀 쓰기와 표준의 판 꼴로 쓴다. 표준·규제 원문이 뒷받침하는 문장은 좁혀 쓰지 않는다. 표준 이름을 주어로 쓰면 현행 규정은 판 연도를 붙여 현재 시제로 쓰고, "<표준>에서 …다", "<표준>에 따르면 …다"처럼 표준을 부사어로 두지 않는다. 개념이나 모듈을 주어로 써도 된다. 반영안의 출처 표시와 넣을 자리는 좁혀 쓰기 절의 출처 구간을 따른다. 같은 출처는 판 단위이고, 다른 출처의 반영안은 구간 한가운데 넣지 않는다. 반영안이 일반 명제로 구간을 끊거나 구간 첫 자리를 바꿔 다른 문단의 출처 표시를 되살려야 하면 그 반영안도 함께 낸다.
5. 반영안의 용어와 약어 풀이는 `docs/wiki-terms.md`에 결정이 있으면 따르고, 없으면 위키 규약 용어 절의 순서로 고른다. 대상 페이지와 `content/`를 grep한 기존 표기는 그 순서에 맞을 때만 따르고, 어긋나면 `근거`에 적는다. 약어와 새로 정의하는 용어는 위키 규약의 약어, 강조 절대로 쓴다. 약어 풀이도 주장이라, `docs/wiki-terms.md`의 풀이 결정이 아닌 풀이는 반영안 문장처럼 인용 키와 위치를 단다(위키 검증의 판정 절). 다른 페이지가 같은 글자를 다른 뜻의 약어로 쓰면(alias 등) 위키 규약 약어 절의 다른 뜻으로 쓰인 약어 규칙대로 풀이한다.

`(게시됨)` 항목은 위키 검증의 정정 절대로 판정한다.

출처는 `.claude/skills/wiki-ingest/verifier.md`의 출처 여는 법대로 열고, 받은 파일은 `<작업 폴더>`에 둔다. 열리지 않으면 매달리지 않는다. 다른 출처로도 뒷받침하지 못하면 `미검증`으로 두고 다음 항목으로 넘어간다.

반환은 아래 JSON 하나다. `주장`은 이슈 본문 그대로 옮기고, 메모와 반영안은 자기 말로 쓴다(위키 규약의 출처 문장 절).

```json
{
  "items": [
    {
      "슬러그": "",
      "주장": "<이슈 본문의 주장 그대로>",
      "라벨": "",
      "메모": "",
      "근거": "<출처의 어디가 무엇을 말하는지, 판 차이>",
      "반영안": [
        {
          "페이지": "<슬러그>",
          "자리": "<절 제목과, 어느 문장 뒤나 어느 문장 대신인지>",
          "문장": "<문장> [@<키>] (<위치>)",
          "기존": "<고치는 경우 바뀌는 기존 문장과 인용 키, 아니면 null>"
        }
      ],
      "grep": "<핵심어와 걸린 페이지, 없으면 없음>"
    }
  ],
  "entries": [{ "key": "", "type": "", "fields": {} }],
  "범위 밖": [{ "페이지": "", "고칠 곳": "", "출처": "" }]
}
```

- `메모`: 이슈 본문 항목 줄에서 `— ` 뒤에 붙일 부분. 꼴은 판정 라벨 절을 따르고, 한두 문장으로 쓴다. 미검증의 시도한 출처는 재조사가 연 1층 후보다(인제스트의 것은 코멘트에 있다). 판 차이나 출처 사이의 사정처럼 판정의 근거는 `근거`에 적는다
- `반영안.문장`: 인용 키와 위치(절, 쪽, 표)를 끝에 단다. 위치는 메인 세션이 원문과 다시 대조할 때 쓰고, 게시할 때 뺀다. 출처 둘 이상이면 키마다 위치를 단다
- `entries`: `bib/`에 없는 새 키만(`ls bib/`로 본다). 위키 규약의 인용 절의 키 꼴과 필수 필드를 따르고, `urldate`는 오늘이다
- `범위 밖`: 항목과 다른, 게시된 페이지의 틀린 곳이나 고칠 곳. 반영안에는 넣지 않는다
````
